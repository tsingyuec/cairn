# 生物学、模型与数据知识体系

这套目录按**科学概念与问题**组织：公共基础解释可复用概念，模型专题解释方法如何解决具体问题，数据专题解释原始资源记录了什么、证据来自哪里。它不是部署手册，也不是把平台模型或页面逐个排列的产品清单。

当前共 **28 条知识脉络、1406 个三级小节**（973 个自有写作小节加 433 个通用复用条目）。每条叶子脉络独立目录，各自少于 100 个小节，分类合计与项目总数没有 100 上限；初始版本仅编写知识目录，后续进度以各脉络 README 为准。沿用 video2blog-content 的站点展示和小节处理方式，不导入其已有博客。

## 如何阅读

1. 先读 B01，建立“生命层级 → 信息流 → 分子功能 → 细胞与个体 → 科学证据”的共同主干。
2. 按问题选择生物学分支；数学或机器学习基础不足时先补 M01，再选序列、图与几何、生成机制。
3. 直接进入目标专题，按章节目录顺序学习：其中 `[REUSE]` 小节链接所需的通用基础，紧挨着专题扩展小节；不需要先通读 M01 等整门课程。模型只是机制案例，课程同时覆盖方法谱系。
4. 配合数据专题理解真实数据对象、实验设计与证据等级，再回到模型的训练和评估。

专题的章节目录就是学习顺序；基础分支也只补目录指定的部分，已掌握者可跳过相应 `[REUSE]` 条目，不要求先通读全部主干或全部模型基础。跨脉络的“学习出口”和“关联”可形成知识网络，不表示全部是前置依赖。

## 目录约定与引用方式

- 每份 README 用“章（`## 1`）—节（`### 1.1`）—小节（带编号的列表行）”组织；编号小节行计入脉络规模，其中自有写作任务带进度状态，`[REUSE]` 条目链接通用基础、无进度状态。
- 小节行保留稳定锚点，并以 `[WAITING]` / `[PROCESSING]` / `[DONE]` / `[ABORT]` 结束；新任务从 WAITING 开始。正文按“节/小节”落位，不另建章目录，具体见[小节处理规则](../.agents/skills/extend-knowledge/processing.md)。
- B 表示生物学基础，M 表示通用模型基础，P 表示模型专题，D 表示数据专题。编号用于引用，中文目录名说明主题。
- 标题直接写知识主题与关键知识点，例如“文档结构解析：版面分析、阅读顺序与跨页分块”。“如何／怎样”的学习问题及范围说明放在学习目标中，不直接用作目录标题。
- 每个目录节点都有显式锚点，例如 `b01-2-2-1`；专题中的“复用”直接链接到基础小节，“关联”连接专题内容。
- 课程路径完整，正文主归属唯一。共享基础作为 `[REUSE]` 小节进入专题章节，不再只是整门课链接；但不复制文章、不重复建立同一采集任务。
- 小节按独立机制、推理链或判读任务划界，不把整套模型或整章压成一个任务。默认 1–3 篇是素材预算而非完成标准；同一规范博客可由多个小节的导读引用，不重复整理整场报告，也不因共用视频就合并教学目标。
- 小节编号和锚点按长期引用维护；目录建设期间的重排和本轮拆分均有记录，见[分阶段映射说明](../docs/目录审查/README.md)与[章节整合说明](../docs/目录审查/2026-11-20-章节整合说明.md)。历史目标须沿映射链解析；未来重排仍须记录并修复入链，不随意重编号。
- 这里的目录是编写计划，不把尚未存在的正文文件做成假链接。

### 原始资源的边界

- “原始资源”是该数据提供方的官方发布，不强求它是未处理的实验读数。例如 scPerturb 本身整合多个研究，scBaseCount 本身统一重处理公共测序数据；仍应沿其官方发布和原研究理解数据。
- 不将 biodata 的 `singlecell` 整合站点、`pfam_interpro_legacy` 历史目录名、数据库表、二次筛选或 API 作为知识分类依据。
- scBaseCount 与 CELLxGENE 分别保留原始身份；BioProject/BioSample 是实验来源链，不能把平台追加的映射当作原站事实。
- Velocyto 的 spliced/unspliced 等计数与 RNA velocity 推断分开；不会把发布的计数文件说成已拟合好的细胞动力学。
- OLS 收录许多本体，本目录优先覆盖与当前生物问题相关的核心本体，不机械地把数百个本体都展开为课程。
- 内部抗体实验没有经仓库确认的公共原站。保留一手实验脉络是为了覆盖真实数据，并明确其授权与血缘边界。
- 原站的总体规模、官方可下载范围和本地已有范围是三回事；目录不把本地筛选或处理结果冒充原站全量。

## 范围依据与后续扩展

初始选题基于来源模型仓库的配置、模型文档及数据仓库的原始资源说明；详见[来源说明](../docs/来源说明.md)。这些只是选题线索，不把二次实现当作科学事实。cairn 本身不承载模型服务或数据镜像，不依赖相邻仓库才能阅读和校验；模型注册不代表服务健康，官方资料链接也不代表已在线逐条核验。

后续写正文时，每个小节补充核心问题、概念解释、必要图示或公式、与前后节点的连接及原始文献。模型的架构、数据、版本和实验结论需分别溯源；资源许可和覆盖范围依官方当前发布确认，不从软件许可证或本地实现推断。

新增内容优先放入已有科学主线；若接近 100 小节，按独立科学问题拆分并保留公共引用，不按版本号或供应商机械分裂。
