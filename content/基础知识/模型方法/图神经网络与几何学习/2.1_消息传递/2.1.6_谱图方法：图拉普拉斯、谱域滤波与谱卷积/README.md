# 2.1.6 谱图方法：图拉普拉斯、谱域滤波与谱卷积 · 导读

本节回答一个问题：GCN 的归一化邻域聚合不是凭空写出来的，它从"图拉普拉斯 → 图傅里叶变换 → 谱域滤波 → 多项式/切比雪夫近似 → 一阶简化"这条推导链上掉下来。读完应能自己走一遍这条链，并说清它在哪一步变成了空间消息传递。

本节只讲**谱滤波与谱卷积本身**。把拉普拉斯特征向量当作节点坐标拼进输入（位置/结构编码）是另一件事，由 [2.3.2 图上的位置编码与结构编码](../../2.3_图表示能力、位置编码与异质图/2.3.2_图上的位置编码与结构编码：拉普拉斯特征向量、随机游走与距离编码/消息传递看不见你在哪：图上的位置编码与结构编码及其代价.md) 承担，本节不重复其符号、重根与代价讨论。

## 学习目标覆盖

- **图拉普拉斯 $L=D-A$ 为什么是差分算子**：由《第04讲：图神经网络》§3.2「拉普拉斯矩阵 $L=D-A$ 是图上的差分算子」与 §3.3「用 $L$ 乘图信号：衡量节点与邻居的差异」覆盖。§3.2 给出 $D$ 的定义与 $L=D-A$ 的构造；§3.3 把 $Lf$ 逐节点展开成 $h(i)=\sum_{v_j\in\mathcal{N}(v_i)}\big(f(i)-f(j)\big)$，说明它只关心相邻节点之间变了多少，不关心信号本身多大。§3.3 同时给出二次型 $f^TLf=\tfrac12\sum_{i,j}A[i,j]\big(f(i)-f(j)\big)^2$，并解释为什么必须平方——直接对差值求和会正负抵消——由此把 $f^TLf$ 读成"图信号的光滑度"，并对应到低频/高频。§3.1 先交代"图信号 = 节点特征矩阵 $X$"这一术语对照，是读懂后面所有式子的前提。
- **半正定与特征分解**：由 §3.4「半正定性：为什么拉普拉斯矩阵可以做特征分解」覆盖。$f^TLf$ 是一堆平方项之和，故 $L$ 半正定；半正定保证可特征分解 $L=U\Lambda U^T$，$U$ 的列标准正交，特征值非负且可排成 $0=\lambda_0<\lambda_1\le\cdots\le\lambda_{N-1}$；最小特征值 0 对应常向量，即最光滑的信号。§3.5「特征向量就是一组'图信号基'，特征值就是频率」进一步用 $u_i^TLu_i=\lambda_i$ 说明特征值就是该特征向量作为图信号的频率，并把 $N$ 个正交特征向量读成 $N$ 维空间的坐标轴。
- **图傅里叶变换**：由 §3.6「图傅里叶变换：空间域与谱域之间的来回切换」覆盖。正变换 $\hat f=U^Tf$（系数由内积 $\hat f_i=f^Tu_i$ 得到）、反变换 $f=U\hat f$，以及空间域/谱域两个视角的差别：空间域看"哪个节点取什么值"，谱域看"由哪些频率组成、各占多少"。
- **谱域滤波三步（变换—过滤—反变换）**：由 §4.2「谱滤波的三步：变换、过滤、反变换」覆盖。$\hat f=U^Tf$ → $\hat y_i=g(\lambda_i)\hat f_i$ → $y=U\hat y$，合起来 $y=Ug(\Lambda)U^Tf$；并给出低通/高通/带通的直观含义："滤波器形状决定保留哪些频率"。§4.3 补两个工程问题：$g$ 从数据里学、多通道时要 $d_1\times d_2$ 个滤波器（$F'=Ug(\Lambda)U^TF$）。§4.1 先放了一个 1990 年代的"邻居聚合"原型作对照，是后面 §4.8 比较的参照物。
- **非参数滤波器**：由 §4.4「非参数滤波器：最灵活，但参数多、算不起」覆盖。$g$ 直接取 $N$ 个可学习参数 $\theta_1,\dots,\theta_N$；两条致命代价是参数量 $O(N)$ 与必须做 $N\times N$ 特征分解（"$N\times N$ 矩阵的特征分解非常费时，扩展性很差"）。
- **多项式滤波器**：由 §4.5「多项式滤波器：用 $K+1$ 个参数共享所有频率」覆盖。$g(\lambda)=\sum_{k=0}^K\theta_k\lambda^k$，参数从 $O(N)$ 降到 $O(K)$；利用 $U\Lambda^kU^T=L^k$ 把滤波写成 $\sum_k\theta_kL^kf$，从而**不必做特征分解**，只剩稀疏矩阵乘法；并指出 $L^K$ 的非零结构与长度 $K$ 的路径对应，即"从 $K$ 跳邻居内聚合"，这是谱设计落到邻居聚合的第一处伏笔。同节还点出多项式基 $1,x,x^2,\dots$ 不正交、训练不稳。
- **切比雪夫多项式**：由 §4.6「切比雪夫多项式：正交基让训练更稳定」覆盖。递推定义 $T_0=1,T_1=x,T_k=2xT_{k-1}-T_{k-2}$；把特征值缩放到 $\tilde\Lambda=\tfrac{2\Lambda}{\lambda_{\max}}-I\in[-1,1]$，对应空间域 $\tilde L=\tfrac{2L}{\lambda_{\max}}-I$；收益是正交基带来的稳定性与高次幂不爆数值，代价结构不变（仍 $K+1$ 个参数、仍免特征分解）。讲者把这条线总结为"任意多项式 → 基本多项式 → 切比雪夫多项式"。
- **GCN 的一阶简化与重归一化**：由 §4.7「GCN 是切比雪夫滤波器的'一阶简化'」覆盖。三步简化（$K=1$；$\lambda_{\max}=2$；令 $\theta=\theta_0=-\theta_1$）得到 $\theta\big(I+D^{-1/2}AD^{-1/2}\big)f$；再加 self-loop $\tilde A=A+I$ 并重归一化 $\hat A=\tilde D^{-1/2}\tilde A\tilde D^{-1/2}$，最终 $F'=\hat AF\Theta$。同节给出判断："GCN 本质上只是切比雪夫滤波器的一个特殊形式"，且实践中常不输完整切比雪夫版本。
- **谱方法与空间消息传递的对应**：由 §4.8「空间域解释：GCN 就是在'邻居 + 自己'上加权求和」与 §5.4「MPNN：把上述方法统一成'消息传递 + 更新'」两处共同覆盖。§4.8 把 $\hat A$ 的一行读成聚合权重，$F'_i=\sum_j\hat A[i,j]F_j\Theta$，并逐条列出它与最早图滤波的四处差别（self-loop、$\Theta$ vs MLP、度归一化、是否输入原始信息 $l_i$），最后给出本节要的判断：只看空间域会以为"反正就是邻居聚合"，只有走完谱域推导才知道权重为什么长这样、为什么需要 self-loop 与归一化。§5.4 则给出统一形式 $m_i=\sum_{v_j\in\mathcal{N}(v_i)}M(F_i,F_j,e_{(v_i,v_j)})$、$F'_i=U(F_i,m_i)$，并明确"GCN 的 $M$ 是线性变换加归一化权重，$U$ 是求和"——这就是"谱方法 ↔ 空间消息传递"的落点。旁证：§4.5 的 $L^K$ 路径解释已经说明谱域多项式滤波在空间域就是 $K$ 跳聚合，§6.3–§6.4 又把 GCN 读成"图信号降噪只走一步梯度下降"，说明谱视角与聚合视角解的是同一个优化问题。
- **与 2.3.2 的分工**：2.3.2 把同一个 $L$ 的特征向量当**坐标**用——取前 $k$ 个特征向量做 eigenmap 拼进节点输入，并讨论符号不定、重根、$k$ 可变三项代价与随机翻符号/DeepSets/SignNet 三种处理办法；本节把 $L$ 当**算子**用——在特征向量基上做滤波（$Ug(\Lambda)U^T$），关心的是滤波器形状、参数化方式与近似阶数。2.3.2 正文已显式声明这一分工（其 §三末尾："同一个 $L$，两种用法：一种是算子，一种是坐标"），本节反向引用即可，不重述位置编码的代价与修补方案。

## 边界提醒

- **术语**：第04讲全篇用"图滤波/谱滤波/谱图滤波"，未出现"谱卷积"一词。本节的"谱卷积"指的就是 $y=Ug(\Lambda)U^Tf$ 这一步——在谱域把滤波器与信号逐频率相乘再变回空间域；博客没有单独推导卷积定理，也没有把"卷积"与"滤波"两个叫法对照说明。这是命名层面的缺口，不是内容缺口（数学对象是同一个）。
- **拉普拉斯变体未展开**：博客只在 §4.7 的 GCN 推导里用到 $D^{-1/2}AD^{-1/2}$，从未把对称归一化拉普拉斯 $L_{\text{sym}}=I-D^{-1/2}AD^{-1/2}$ 与随机游走拉普拉斯 $L_{\text{rw}}$ 作为一族矩阵列出，也没讲"零特征值重数 = 连通分量数"。若需要这一层，须另找素材。
- **跨图迁移性未讨论**：博客讲了特征分解贵（§4.4）、讲了 $L^K$ 的局部性（§4.5），但没有正面说明"非参数/低阶谱滤波器绑定在具体图的特征基上，换一张图不能直接复用"这一谱方法的经典局限。本节导读不代写这条判断。
- **过平滑、PPNP/APPNP 的完整推导**属 §6，与 2.2.2（过平滑）和本节相邻但不同任务；本节只借用 §6.3–§6.4 作为"谱视角 = 降噪"的旁证，不展开。

## 覆盖缺口

1. **"谱卷积"命名与卷积定理**：第04讲只说"滤波"，没有把谱域相乘等价于空间域卷积这一步讲出来，也没有与"卷积"一词对照。术语来源需在导读中说明，正文无对应段落。
2. **拉普拉斯矩阵族**：对称归一化拉普拉斯、随机游走拉普拉斯、以及零特征值重数与连通分量的关系均未出现；博客只给出组合拉普拉斯 $L=D-A$ 与 GCN 里的 $\tilde D^{-1/2}\tilde A\tilde D^{-1/2}$。
3. **谱方法的跨图迁移局限**：博客讲了特征分解的复杂度，但没有明确"滤波器依赖特定图的特征基、不能跨图复用"这一条；本节不硬写。
