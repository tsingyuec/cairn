# 2.1.2 边特征与边更新：有向消息与键类型 · 导读

本节以《AlphaFold Decoded： Evoformer (Lesson 5)》为主博客，讲清“边特征”与“有向边更新”；离散的键类型/关系类型由 2.1.3 已落位的《第04讲：图神经网络》§5.3 补充。

## 学习目标覆盖

- **边特征如何进入消息与更新**：由《AlphaFold Decoded： Evoformer (Lesson 5)》§一 1.1（pair 表示 $z_{ij}$ 的形状与含义）、§三 3.1–3.2（pair 表示作为注意力的加性偏置）、§六 6.1（三角乘法：沿第三点 $k$ 聚合 $A_{ik}\odot B_{jk}$ 更新 $z_{ij}$）、§六 6.2（三角注意力：用 $b_{jk}$ 与转置 $b_{ki}$ 作为偏置）覆盖；§四 outer product mean 补充“节点信息如何写回边”。
- **方向如何进入消息与更新**：由同篇 §五 5.2（$z_{ij}$ 与 $z_{ji}$ 是两个分开的条目）、§五 5.3（outgoing 沿行、incoming 沿列两套更新）覆盖；§六 6.1–6.2 的转置操作说明方向不一致时结果不同。
- **键类型信息的传递路径**：由《第04讲：图神经网络》§5.3（ECC 与 GGNN 把边的类型和方向纳入聚合）覆盖——离散键类型经“按类型分开的变换/消息函数”进入聚合；§5.4（MPNN 统一成消息 + 更新）给出边特征与节点特征互相写入的通用形式。Evoformer 的 pair 特征是连续边特征，不承担离散键类型，这一点在选题单中已注明。
