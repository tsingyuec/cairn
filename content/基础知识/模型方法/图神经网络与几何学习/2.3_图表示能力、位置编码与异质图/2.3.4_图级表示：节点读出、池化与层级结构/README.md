# 2.3.4 图级表示：节点读出、池化与层级结构 · 导读

本节只回答一个问题：节点表示已经算好之后，用什么操作把它压成一个图向量，以及这个压缩动作对"节点顺序"和"图大小"隐含了什么假设。多尺度表示为什么能扩大感受野属于 4.2.1，本节不重讲动机。

## 学习目标覆盖

- **求和/均值/最大读出的差别与适用条件**：由《第04讲：图神经网络》§7.2「平面池化：平均、最大、虚拟节点、注意力加权」覆盖。该段给出两条读出公式——平均池化 $f_G[i]=\text{ave}(F_{:,i})$ 与最大池化 $f_G[i]=\max(F_{:,i})$——并当场给出适用条件：平均池化保留"整体水平"，最大池化保留"最突出的特征"，"比如判断一张图里有没有某个子结构，最大值可能比平均值更敏感"。同段还给出注意力加权求和 $f_G=\sum_i s_i\tanh(F_i\Theta_{ip})$，$s_i$ 为 softmax 归一化的节点重要性，说明读出不必对节点一视同仁。**求和读出本身在 §7.2 没有单列**：sum 只以"注意力加权求和"和 §4.8、§5.4 的聚合形式出现。可迁移的补足证据在同系列《零基础多图详解图神经网络（GNN／GCN）【论文精读】》§5.2「五组实验的结论」末条"聚合操作没有万能"：$\{2,4\}$ 与 $\{4,4\}$ 用 max 都得 4、区分不开，mean/sum 能区分；$\{3,3\}$ 与 $\{3\}$ 用 max/mean 都区分不开，**只有 sum 能**；而 sum 又会被"加起来一样"的反例骗过——结论是"没有一种聚合天生更好，要按任务选"。§5.1 把求和/按元素平均/按元素 max 列为可选的汇聚操作，§5.2 报告在该分子数据集上三者几乎等价。注意这两处的语境是邻居聚合，迁移到图级读出时公式同形，但讨论对象从"一个节点的邻居"换成"整张图的节点"。
- **平面池化与层级池化（DiffPool 等）的差别**：由《第04讲：图神经网络》§7 整章覆盖，四段分工明确。§7.1「池化的目标：从 $N$ 个节点到一个图向量」给主线 $N\to N_p\to\cdots\to1$，并指出池化与滤波的根本差别是**同时改变拓扑和特征**（既得 $A_p$ 又得 $F'_p$）。§7.2 是平面池化：一步到位，平均/最大/虚拟节点/注意力加权四种做法；其中虚拟节点"额外加一个节点，让它和所有节点相连，用它的表示作为整张图的表示"，讲者把它类比成 NLP 里用于分类的特殊 token。§7.3「层次池化：一步步粗化，尽量少丢信息」给层级路线的动机（每步只合并少量信息、中间可穿插滤波）与两条实现路线——**保留重要节点（采样）**与**合并子图为超节点（聚类）**，并明确"层次池化不一定比平面池化效果好"：任务只需粗粒度全局判断时平面池化可能就够，任务依赖层次结构（分子中的官能团、社交网络中的社区）时层次池化更有优势。§7.4 gPool 与 SAGPool 属采样路线（投影向量或 GCN 打分、取 Top-$N_p$、$A_p=A[idx,idx]$、$F'_p=F_{inter}\odot\text{sigmoid}(y)$ 门控），§7.5 DiffPool 属聚类路线（GCN 生成软分配 $S\in\mathbb{R}^{N\times N_p}$，$A_p=S^TA S$、$F'_p=S^TF_{inter}$，软分配因此能表达重叠社区），§7.6 EigenPooling 同样走超节点路线但在谱域做（谱聚类分子图、取前 $K$ 个傅里叶系数，一并解决"子图大小不一导致超节点特征维度不齐"与"逐子图特征分解太贵"两个问题）。
- **节点顺序（置换不变）如何影响图级预测**：由《节点嵌入跟着编号一起搬家：GNN 的置换等变性》§6「图级不变性从哪来：池化把顺序吃掉了」覆盖，这是本节最直接的依据。该段给出图级输出 $y=\sigma[\beta_K+\omega_K H_K\mathbf{1}/N]$，并说明把 $H_K$ 换成 $H_KP$ 后结果不变，原因是置换矩阵乘全 1 向量仍是全 1 向量：**对列求和（或求平均）这个动作把列的顺序信息吃掉了**，"图级不变性不是额外加的约束，而是池化方式自带的后果"。同段还给出反例：把节点嵌入直接拼成长向量再送全连接层，顺序信息就会漏进去——拼接对置换敏感。配套的《节点编号只是记账，图级输出不该跟着变：GNN 的置换不变性》§3 说明顺序敏感的 GNN 会把矩阵当图像看、把"换了编号"误判成"换了数据"，同一张图可能得到两个标签；§4 说明聚合沿局部拓扑走、局部拓扑不认编号，所以不变性来自聚合方式而非训练。读出之前的"汇聚"雏形见《零基础多图详解图神经网络（GNN／GCN）【论文精读】》§3.4「汇聚：缺哪类向量就补哪类」——把相连的边向量与全局向量加起来（维度不同先投影）得到代表某对象的向量，缺哪类属性就从别的属性汇聚过来；§4.5「全局向量 = master node」把虚拟节点讲成与所有顶点、所有边都相连的 $U$，与 §7.2 的虚拟节点是同一构造。
- **图大小（读出归一化）如何影响图级预测**：由上述 §6 的 $H_K\mathbf{1}/N$ 覆盖归一化这一半——除以 $N$ 就是按节点数取平均，均值读出因此对图大小不敏感；求和读出没有这个 $1/N$，输出量级随图大小增长。两者差别的判别证据在《零基础多图详解…》§5.2 的 $\{3,3\}$ 与 $\{3\}$ 反例：max 与 mean 都区分不开，只有 sum 能——这正是"sum 编码了节点数、mean 把它除掉"的直接后果。这一条需要把两处拼起来读，**没有一处直接对比 sum 随 $N$ 增长、mean 归一化的表述**，记为缺口（见下）。
- **预测对象与读出方式的关系**：由《第04讲：图神经网络》§2.2「两类任务：节点级与图级」覆盖——节点级任务靠图滤波，图级任务"节点表示只是中间产物，最终要把许多节点的表示'压缩'成一个图表示"，这才需要池化；§2.4「图池化：拓扑和特征一起变小」补上"当图被池化成一个节点时，这个节点的表示就代表整张图"，§2.5 给出图级框架 = 节点级框架 + 末尾一次图池化，§7.1 再从"整张图怎么表示"的角度重述一遍。三类任务（图层/顶点/边）的划分另见《零基础多图详解…》§1.4。
- **与 4.2.1 的分工**：4.2.1 的两篇讲的是"多尺度表示如何扩大有效感受野"，池化在那里是**手段**：《池化要一层层粗化：图池化如何把邻域压成超节点并扩大感受野》§二平坦池化、§三门控全局池化、§五层级池化、§六粗化两条路、§七下采样池化三要素与手算例子、§八 gPool 四步、§九"只看节点特征、不看结构"的局限；《局部消息传递看不远：多尺度图U-Net如何用粗化扩大感受野》§五三条扩大感受野路线、§六几何图 U-Net 的编码器粗化与解码器细化、§七点池化与稀疏池化、§八压缩与采样比例的代价。本节把这些算子换一个问法：**压完之后图表示里还剩什么，这个压缩对节点顺序和图大小做了什么假设**。因此本节不推导 U-Net 编解码、不讨论采样比例与压缩代价、不把池化当感受野工具；需要 gPool 的手算细节或"打分只看特征不看结构"的批评时，回 4.2.1 那两篇。

## 边界提醒

- §7.2 的**注意力加权池化**与 2.1.5 的 GAT 不是同一件事：那里归一化范围是整张图的节点、输出是一个图向量；GAT 的归一化范围是单个节点的邻居集合、输出仍是节点特征。
- §7.2 的虚拟节点与 2.1.1 §4.5 的 master node 是同一构造的两种叫法（都对应记号里的 $U$），不要当成两种机制。
- 本节讲的是"节点表示 → 图表示"的读出，不涉及图级标签怎么构造、监督粒度怎么选，那属于 5.1.5（已落位）与 5.1.6（未落位）。

## 覆盖缺口

1. **求和读出的独立公式与量级讨论**：§7.2 只给平均与最大两条公式，sum 仅作为注意力加权求和的一部分出现；"sum 读出随图大小增长"没有直接段落，只能由 §7.2 的平均公式 + 2.1.1 §5.2 的 $\{3,3\}$/$\{3\}$ 反例 + 2.2.1 §6 的 $1/N$ 拼合得出。
2. **跨图大小的读出行为**：同一模型在节点数差异大的图上如何保持输出可比（mean 的 $1/N$、sum 的量级漂移、batch 内不同大小图如何拼张量）没有专门段落；2.1.1 §6 只提到"做 batch 时不同顶点邻居数不同、怎么合并成规整张量是个有挑战的问题"，未落到读出。
3. **层级池化与预测对象的搭配**：多任务读出（同时要图级标签与节点标签）、层级池化后节点级预测如何映射回原节点，无素材；5.1.6「节点分类、边预测与图级性质」尚未落位，不能作为本节依据。
