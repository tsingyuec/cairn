# 3.1.3 几何变换下的不变预测与等变预测 · 导读

本节把 3.1.2 的"哪些物理量该变、哪些不该变"落到预测接口上：模型吐出来的东西是标量还是向量，决定了它必须对哪些变换保持不变、对哪些变换同步变化。变换与手性本身的分类、以及逐项物理量的行为表由 3.1.2 承担，本节只讲预测层面的选择。

## 学习目标覆盖

- **不变预测与等变预测的含义（标量侧）**：由《几何深度学习（五）：EGNN 等变性几何图神经网络》§1.1「不变性：标量的性质」覆盖——键长、夹角、二面角这些量"都可以用一个标量表征，而标量不具备方向性"，所以分子在空间中怎么移动它们都不变；§五.1 进一步说明节点特征 $h$ 的整条计算链路（$h_i$、$h_j$、距离、边特征）里没有方向性信息，因此归纳偏置是**不变性**而非等变性。标量输出的具体例子由《旋转与平移只换参考系，反射会翻转手性》§七给出：能量对旋转、平移、反射三类变换全不变，对映体结合亲和力是"手性相关标量"——反射下换到另一个对映体，数值可以不同。
- **不变预测与等变预测的含义（向量/坐标侧）**：由同一篇 EGNN 博客 §1.2「等变性：向量的性质」与 §五.2 覆盖——向量具备方向性，空间一变它就跟着变；模型里等变性的实际载体是**坐标分支**，$r_{ij}=x_i-x_j$ 是向量减法得到的方向向量，坐标更新 $x_i^{l+1}=x_i^{l}+\frac{1}{C}\sum_j r_{ij}\,\phi(m_{ij})$ 让输出坐标随输入同步变换。§五.2 的推导把这个性质写成一句可检验的话："先变换再过模型 = 先过模型再变换"：把更新式里所有含空间的项同时乘 $Q$ 加 $t$，平移项相减抵消、$Q$ 提到求和号外，化简后正好回到"先变换后更新"的形式。向量输出的物理例子见 3.1.2 §七：偶极矩随旋转转、随反射翻，且方向还被分子对称性约束（有主轴时只能沿主轴，同时有主轴和 $\sigma_h$ 时必须为零）。
- **判断任务只需不变还是需要严格等变**：由三处合成。①**输出类型**：EGNN §3.3 用 SchNet 说明"因为距离属于不变量，所以整个模型通过距离建模实现不变性"——只打包标量的模型天然只能给不变输出；§3.5 指出 EGNN 相对它的改动就是多拼了距离并新增坐标分支，输出才带上方向。②**标签是否随变换**：3.1.2 §七的表格逐项列出能量、距离、键角、带符号二面角、旋光符号、对映体亲和力在旋转/平移/反射下的行为，标签对哪类变换变号或换值，就要求模型对哪类变换敏感。③**下游是否要用方向**：EGNN §1.3 给出动机——蛋白质的功能与三维结构直接相关，"结构在空间里发生形变，属性与功能会跟着变化"，所以要把等变性写进先验；§四.2 的坐标更新则说明当任务要吐出结构时，输出必须走向量分支。3.1.2 §八把这三条收敛成三档建模约定：只用 2D 图的模型完全对手性不变；$E(3)$ 不变的三维模型"从根本上无法区分镜像对映体"；$SE(3)$ 不变的三维模型原则上能区分对映体，但会把构象变化误判成手性差异（SphereNet 隐空间实验：手性中心附近转键后两簇重叠）。
- **几何变换对标签与输出的约束**：**标签侧**由 3.1.2 §七、§八覆盖——标签按"是否依赖手性 + 是标量还是向量"来构造：要学手性就得用反射下变号的量（带符号二面角、旋光符号）或手性敏感标量（对映体亲和力）；只用距离和键角做标签/特征，等于宣布手性不重要。**输出侧**由 EGNN §四.1、§四.2、§五.2 覆盖——坐标输出不是自由回归出来的，而是由"标量系数 $\phi(m_{ij})$ 乘方向向量 $r_{ij}$"聚合而成，正因为每一项都带着同一个 $Q$，求和后才等变；反过来，若输出空间不这样约束，§五.2 的等价关系就不成立。**直接回归坐标为什么要注意等变性**：本节只能给出必要条件式的读法（输出必须由等变分量拼出，见上），没有一篇博客给出"不变特征 + MLP 直接回归坐标会破坏等变"的反例论证，此点记为缺口，见下。
- **与 3.1.2 的分工**：3.1.2 §八 末段已明确划界——该节"只讨论变换本身和哪些量该保持"，而"把'输出随输入变换而变换'写成公式、判断一个任务该要严格等变还是只需不变，是 3.1.3 的内容"；不变量特征、数据增广、等变架构三条路线的取舍归 3.1.4，$E(3)$ 与 $SE(3)$ 模型的系统对照归 4.1.1。本节因此不复述 proper/improper、手性中心、点群判据，只引用其结论。

## 边界提醒

- 本节说的"不变/等变"专指三维坐标变换（旋转、平移、反射）。节点顺序的置换不变/等变是 2.2.1 的内容，两者形式相似但对象不同，不要互相套用。
- "$E(3)$ 等变"与"$SE(3)$ 等变"的差别不在架构复杂度，而在允不允许反射：前者对手性天生不敏感，后者才可能区分对映体。选哪一个属于本节的任务判据，具体模型对照留给 4.1.1。
- 3.1.2 §八 提到的 ChiRo 编码器属于架构设计，本节不展开。

## 覆盖缺口

1. **"力"作为等变输出**：两篇博客都没有把力（负能量梯度）举成等变预测的例子，EGNN 只讲坐标 $x$ 的更新与"分子属性预测"。导读以坐标与偶极矩作等变输出的例子，力同属此类但无原文段落支撑。
2. **直接回归坐标的反例**：缺少"用不变特征 + MLP 直接回归三维坐标会破坏等变性、对同一构象的不同朝向给出不同答案"的论证。EGNN §五.2 只正面证明按 $\hat m_{ij}\cdot r_{ij}$ 构造时等变成立，可作必要条件读，但不是反例。此项建议后续补素材，本节不代写。
3. **下游用途的显式判据**：EGNN §1.3 只给"结构变→功能变"的动机，没有"下游是力场/结构生成则需要等变，下游是打分/分类则不变足够"的成文判据。导读中这一条是按已有段落归纳，不是原文结论。
