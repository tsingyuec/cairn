# 3.1.4 对称性实现路线：不变量特征、数据增广与等变架构的取舍 · 导读

一个模型"尊重三维对称性"可以有三条完全不同的实现路径：只喂不变量、用变换后的样本训练、或把等变性写进计算图。本节不重复 3.1.2 的变换分类，也不重复 3.1.3 的不变/等变定义，只做一件事：把三条路线各自的**保证、表达力上限和代价**摆到同一张桌上，给出选路线的判据。

## 学习目标覆盖

- **不变量特征路线：距离、角度等不变量输入怎么实现对称性，代价是什么**：由《几何深度学习（五）：EGNN 等变性几何图神经网络》§3.2、§3.3 覆盖。§3.2 讲径向模型——取 $r_{ij}=x_i-x_j$ 的**模长**当距离，送进径向函数得到权重，再用权重给方向向量重新分配重要程度；§3.3 讲 SchNet——距离进径向模型出权重，权重乘上邻居特征的映射结果再求和，讲者用一句话点明这条路线成立的原因："因为距离属于不变量，所以整个模型通过距离建模实现**不变性**属性"。代价分两层：**表达力**上，只打包距离和键角的表示对反射天生是瞎的，$E(3)$ 不变的三维模型"从根本上无法区分镜像对映体"（3.1.2 §八），而且标量与一阶向量看不见四面体/八面体这类角向结构，"至少要保留到 $l=2$ 或 $l=3$"才有信号（3.2.4 §1.3、§6.3）；**计算**上，要把不变量做细就得对距离上径向模型、对夹角上球谐、二面角同理——EGNN §3.5 说这些球面函数的计算"相对复杂"，得到的高阶特征表示也复杂，"随着分子变大、模型变深，计算复杂度呈几何级增长"。所以不变量路线不是"免费的简化"，而是拿表达力换计算，或者拿计算换表达力。
- **等变架构路线：高阶特征与坐标流怎么实现对称性，代价是什么**：由同一篇博客 §3.4、§3.5 与 §四 覆盖。§3.4 是 TFN 一类**高阶可导向特征**（steerable features）路线：消息定义里带一个与 Clebsch–Gordan 系数相关的权重矩阵，特征按阶组织，只对旋转和平移等变、不含反射；§3.5 与 §四 是 EGNN 的**坐标流**路线：消息里直接拼进距离，另设一个向量分支 $\hat{m}_{ij}=r_{ij}\,\phi(m_{ij})$，聚合后坐标更新写成

  $$
  x_i^{l+1}=x_i^{l}+\frac{1}{C}\sum_{j\neq i} r_{ij}\,\phi(m_{ij})
  $$

  等变性由这个式子逐项携带同一个 $Q$ 保证（§五.2）。代价同样是双向的：TFN 一侧，EGNN 摘要把"不需要高计算复杂度、不需要中间层的高阶特征表示"当作卖点（§2.2），而高阶路线本身的分量数按 $(L+1)^2$ 增长、耦合路径"组合地"变多，实际库靠显式声明保留哪些路径来砍成本（3.2.4 §6.1、§6.2）；EGNN 一侧，讲者明确说 TFN"潜力更大"——"训练数据充足时，基于高阶可导向特征的深度模型精度上限更高、表征能力更强"（§2.2），即 EGNN 的便宜是用表达力上限换来的。另外 EGNN 是 $E(3)$ 等变、连反射一起打包，因此对手性不敏感（3.1.2 §八）。
- **数据增广路线：让模型从样本里见到变换**：**本脉络没有一篇博客直接讲三维分子几何的数据增广，此点如实记为缺口**（见下）。可用的支撑只有两处，且都不是分子语境：①《节点嵌入跟着编号一起搬家：GNN 的置换等变性》§二——讲者说这类对称性质"在深度网络里并不容易强制成立"，实践中常见的替代手段就是数据增广，"把原图旋转、平移、做各种变换，让网络在训练中见过这些变换，从而'学会'应对"，并直接给出判断："增广是让网络从数据里逼近对称性，架构等变是把对称性直接写进计算。两者不等价，代价与保证都不同"；②《消息传递看不见你在哪：图上的位置编码与结构编码及其代价》§五把"随机翻符号"称作"第一代：把不唯一当成数据增广"，并列出它的代价——重根问题没处理、变长问题靠保守设定回避、$k$ 被最小的图卡死导致表达力受限。**"增广只让模型见到更多变换样本，不保证输出严格等变"这一判断的支撑段落有三处**：其一，2.2.1 §二把增广定性为"权宜之计"、把架构等变定性为"写进计算"，两者被明确对立；其二，EGNN §五.2 的等变证明是**代数恒等式**——把 $Q$ 提到求和号外、平移项相消，结论对任意输入成立，这类保证只能来自结构，样本再多也给不出；其三，3.1.3 已确立的标签约束说明增广改不了输出接口——标签在反射下变号（带符号二面角、旋光符号）或换值（对映体亲和力）时（3.1.2 §七），模型若输出的是不变量，增广只会让它把两个对映体学成同一个答案。
- **三条路线的取舍判断与"任务是否需要严格等变"**：判据由四处合成，按顺序问。①**输出是什么类型**：只要标量（能量、打分），不变量路线就够——EGNN §3.3 的 SchNet 正是"通过距离建模实现不变性"；要吐坐标或向量，就必须有坐标分支（§四.2）。②**标签对哪类变换敏感**：3.1.2 §七的逐项表给出旋转/平移/反射三列行为，标签变号或换值的变换，模型就必须对它敏感；§八进一步把模型分成三档——2D 图模型完全对手性不变、$E(3)$ 不变模型无法区分对映体、$SE(3)$ 模型能区分但会把构象差异误判成手性差异（SphereNet 隐空间实验：手性中心附近转键后两簇重叠）。③**局部对称性要多细**：3.2.4 §6.3 给出检查点——四面体、八面体环境在 $l=1$ 上没有信号，必须保留到 $l\ge2$ 或 $l\ge3$，这直接决定要不要走高阶等变路线。④**数据量与算力预算**：EGNN §2.2 的定性判断是数据充足时高阶路线上限更高，3.2.4 §6.2 则说明高阶路线的成本主要在"路径表"上，砍路径是刻意的容量取舍。把四条合起来读：**任务需要严格等变**（要方向、要手性、要生成结构）时，增广不足以提供保证，只能走等变架构；**任务只需要不变**（标量性质预测）时，不变量特征最省，但必须接受它对手性和高阶角向结构的天生盲区；**数据少、算力紧、精度要求不高**时，增广是把对称性"近似"进模型的现实手段，代价是它给的是统计倾向而非结构保证。
- **避免把数据增广等同于架构等变**：这一条由上述三处支撑合并而成，另有一个正面旁证——《高阶几何特征：球谐把方向编码成张量，张量积决定阶与阶如何耦合》§七记录了把对称性写进结构的附带性质：随机初始化的网络"还没训练就已经满足这条约束"，输出不会凭空产生输入里没有的不对称，因此"如果输出破坏了输入的对称性，那一定是实现里某处类型用错了"。这句话正好划出两条路线的分界：结构等变是**训练前就成立、可被违反即报错**的约束；增广是**训练后也不保证、无法用输出反查**的倾向。

## 边界提醒

- 本节只比较三条实现路线的取舍。变换本身的分类与逐项物理量行为归 3.1.2；不变/等变的定义与"该要哪一种"的接口判据归 3.1.3；$E(3)$ 与 $SE(3)$ 模型的系统对照归 4.1.1；球谐与张量积的推导归 3.2.4。本节只引用它们的结论。
- 2.2.1 的增广论述发生在**置换与二维图像**语境（旋转、平移、翻转图像），2.3.2 的增广是**位置编码符号**语境。二者能支撑"增广 ≠ 架构等变"这条一般判断，但不能当作"分子几何增广有效"的证据，引用时必须带上这个限制。
- "不变量特征"在本节指**输入侧只保留不变量**（距离、键角、二面角），与"模型输出不变"不是同一件事：前者是特征工程选择，后者是输出契约。两者常一起出现，但不能互相替代论证。

## 覆盖缺口

1. **三维分子几何的数据增广完全没有素材**：没有博客讲随机旋转/平移训练样本、反射增广是否合法、增广倍数与训练成本。本节只能借 2.2.1（置换/二维图像语境）与 2.3.2（符号翻转语境）支撑一般判断，属于跨语境借用，已在正文标注限制。若要把这条路线写实，需要新素材。
2. **数据效率没有定量证据**：只有 EGNN §2.2 讲者的定性说法（"训练数据充足时"高阶模型上限更高），没有"等变架构在小样本上更省数据"的对比实验数字，也没有增广带来的等效样本倍数。
3. **三条路线缺并列对比**：没有一篇博客在同一数据集上同时比较不变量模型、增广训练模型与等变模型；本节的取舍判断是按各篇的分项结论归纳的，不是原文给出的对比表。
4. **"不变量特征 + MLP 直接回归坐标会破坏等变"的反例仍缺**（与 3.1.3 同一缺口）：EGNN §五.2 只正面证明按 $r_{ij}\phi(m_{ij})$ 构造时等变成立，可作必要条件读，不是反例。
5. **增广与等变架构的组合用法**（等变模型上再加增广还有没有收益）无素材，本节不涉及。
