# 3.2.3 几何网络中的标量与向量特征 · 导读

本节要建立的是一张"特征类型 → 允许操作"的对照表：先按旋转下的行为把几何网络里的特征分成标量与向量两类，再看哪些运算能保持这个行为。分工上，标量/向量如何随变换走由 EGNN 的计算流程给出（4.1.2 的博客），"通道"与"阶"的区别由 3.2.4 的类型系统给出；本节只做 0 阶与 1 阶，不进入高阶表示。

## 学习目标覆盖

- **标量在旋转/平移下不变、向量随旋转矩阵变换**：由《几何深度学习（五）：EGNN 等变性几何图神经网络》§1.1「不变性：标量的性质」与 §1.2「等变性：向量的性质」给出定义——键长、夹角、二面角"本质上都可以用一个标量（数值）表征，而标量不具备方向性"，所以分子在空间里怎么移动它们都不变；向量"具备方向性，空间一变，向量也随之变化"。落到具体计算上，§五.1 先把变换写成"用 $Q$（旋转矩阵）加一个偏移量（平移）"作用于坐标 $x$，再指出节点特征 $h$ 的整条链路只有 $h_i$、$h_j$、距离、边信息，"距离没有方向性，节点与边的初始特征也不具备方向性"，因此 $h$ 是不变量；§五.2 则对坐标分支做推导：$x_i^{l+1}=x_i^{l}+\frac{1}{C}\sum_j r_{ij}\,\phi(m_{ij})$ 中 $r_{ij}=x_i-x_j$，把含空间的项同时乘 $Q$ 加 $t$ 后，"平移项相减抵消，把 Q 提到求和外面"，结果正好等于先变换再更新，所以 $x$ 是等变量。逐项物理量的对照表在《旋转与平移只换参考系，反射会翻转手性》§七：能量作为标量对旋转、平移、反射三类变换全不变；偶极矩作为向量"随旋转转、随反射翻"；距离、键角不变，带符号二面角反射下变号；平移的作用见同篇 §四"只挪原点，连朝向都不动"。3.2.4 的博客 §1.1 给出同一件事的刻度说法：标量角频率为 0、反演不变号（偶），向量角频率为 1、反演变号（奇）。

- **哪些操作对标量合法、哪些对向量合法**：五类操作分别落在以下段落。①**拼接**：《EGNN》§3.1 的普通 GNN 三步走把"目标节点 $i$ 的特征、邻居 $j$ 的特征、以及 $i$–$j$ 边的初始特征拼接"后送进网络，§3.5 的 EGNN 消息定义"又加了一个距离信息……直接拼进来"，§五.1 说明这条拼接链里全是无方向性的量——拼接在原文中只出现在标量之间，拼接不改变每个分量的变换行为。②**线性组合**：§4.2 的双分支聚合"标量消息与向量消息各聚各的"，向量分支对 $\hat m_{ij}$ 求和，§4.1 的 $\hat m_{ij}=r_{ij}\,\phi(m_{ij})$ 则是"标量系数乘向量再求和"，即向量的加权线性组合；3.2.4 §4.1 把这条规则说成"按阶分块 + 块内线性混合"天然满足等变。③**模长**：§3.2 的径向模型"再用其模长表征两点间距离，送进径向模型……建模出权重"，§3.3 的 SchNet 同样"计算节点 $i$、$j$ 之间的模长（距离）"——模长是把向量降成标量、从而可以进入任意标量运算的通道。④**门控**：§4.1 的 $\hat m_{ij}=r_{ij}\,\phi(m_{ij})$ 与 §3.2 的"用这个权重对方向向量做重要程度的重分配"，都是标量乘向量：标量定权重、向量保方向，乘积仍是向量。⑤**逐元素非线性**：只有间接支撑——§4.1 里神经网络 $\phi$ 只作用在标量 $m_{ij}$ 上，向量 $r_{ij}$ 始终只被标量乘；3.2.4 §4.1 强调"所有操作都必须遵守类型规则"、旋转只做"块内的线性组合"。两篇都没有直接写出"对向量逐分量套 ReLU 会破坏等变"的反例，此点记为缺口（见下）。

- **为什么不能把"通道数组"都叫几何向量**：由三处合成。①**判据是变换行为，不是数字个数**：《EGNN》§1.2 把"向量"定义为具备方向性、随空间变化的对象；§五.1 明确指出节点特征 $h$ 与边特征"不具备方向性"，所以 $h$ 虽然是一串数、也参与拼接与线性层（§3.1），它是不变量而不是几何向量。②**通道是阶内的位置，不是空间方向**：3.2.4 §4.2 把球谐表读成"行是阶（类型），列是阶内的分量（通道）"，"看到 $l=2$ 有 5 个通道"指的是同一阶内的五个分量；§6.1 进一步给出 $L=1$ 时是"4 个（1 个标量 + 3 个向量）"——通道总数 4 不等于一个三维向量。③**系数不是坐标**：3.2.4 §3.2 明确"把 $f_l^m$ 当成坐标的另一种写法"是易犯的错，球谐系数是"这个函数在第 $l$ 阶第 $m$ 个基函数上投影出多少"。合起来的判据是：看这个数组在旋转下是否按 $Q$ 变换、是否携带三维方向语义，而不是看它的长度是 3 还是 128。

- **与 3.2.4 的分工**：3.2.4 的博客在 SCQA 里已经划界——"上一节（3.2.3）把几何网络里的特征分成两类：标量在旋转下不变，向量跟着旋转矩阵一起转。用这两类特征已经能写出等变的更新规则"，它自己从"3 个数装不下整张球面分布"接着往下走。因此本节只处理 $l=0$（标量）与 $l=1$（向量）两类，以及它们各自允许的操作；$l\ge 2$ 的高阶块、球谐 $Y_l^m$ 作为分阶基、张量积与 Clebsch–Gordan 分解、`0e`/`1o`/`2e`/`3o` 类型标签与路径取舍，全部归 3.2.4，本节不重复推导。

## 边界提醒

- 本节说的"标量/向量"专指三维几何意义上的类型，与编程语言里的"标量/数组"不是一回事；一个 128 维的节点特征数组是标量特征堆叠，不是 128 维几何向量。
- 反射下的行为（向量变号、赝矢量、手性敏感标量）属于 3.1.2 与 4.1.1 的范围；本节只用到"旋转 + 平移"这一组变换来区分两类特征，遇到反射时按 3.1.2 §七的表处理。
- 具体架构层面的标量—向量通道设计（GVP 的向量线性组合、模长、标量门控）由 4.1.4 展开，本节只给操作层面的合法性判据，不展开某个模型的完整更新式。

## 覆盖缺口

1. **逐元素非线性对向量的禁令没有显式段落**：两篇博客都只以"$\phi$ 只吃标量、向量只被标量乘"（EGNN §4.1）和"所有操作都必须遵守类型规则、旋转只在块内线性混合"（3.2.4 §4.1）间接支持"不能对向量逐分量套 ReLU"。缺少一句直接的反例说明（例如对向量分量各自做非线性后不再满足 $f(Qx)=Qf(x)$）。导读按间接支撑写，未代写反例。
2. **拼接对向量是否合法未讨论**：原文的拼接全部发生在标量之间（EGNN §3.1、§3.5），但没有说明"把两个向量直接拼起来会得到 6 个数、不再是一个按 $Q$ 变换的对象，需要按阶分块存放"。此项只能由 3.2.4 §4.2 的"行是阶、列是通道"反推。
3. **"通道数组"这一说法本身没有原文出处**：3.2.4 用的是"分量/通道"，EGNN 用的是"节点特征 $h$"。本节把两者对齐成"通道数组 vs 几何向量"是按两篇归纳的读法，不是任一博客的原话。
