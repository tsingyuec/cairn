# 3.2.2 局部坐标框架：基向量、相对位置与框架变换 · 导读

本节要建立的是一条从"点"到"框架"再到"相对变换"的链路：三个非共线点张成一个平面，平面给出一个法向，法向与平面内两个方向一起构成一组正交基，这组基加一个原点就是一个局部框架；有了框架，邻居的绝对坐标才能被改写成"相对于当前单元"的局部坐标。分工上，框架在残基几何网络里的整体用法（IPA 与 FAPE）由 4.1.3 的博客承担，本节只讲框架怎么构造、相对变换怎么用，不重复 IPA 的打分推导。一般构造步骤与相对变换的显式式子由补齐博客《局部坐标框架：三个点定一组正交基，相对变换把邻居搬进当前框架》§三–§四 承担，导读负责残基框架与 IPA/FAPE 的用法。

## 学习目标覆盖

- **从三个非共线点构造局部框架（基向量、正交化、手性）**：由《第04讲：用 AlphaFold2 / OpenFold 做结构预测》§8.4 末尾关于残基框架的引注与 §8.3 合成，覆盖程度为**部分**。§8.4 给出"三个点定一个平面"这一步：每个残基"由一个框架表示，它其实由 **N–Cα–C** 三个共面原子定义（Cβ 大致垂在侧面），还能算出垂直于该平面的**法向量**"——三点共面、平面给出法向，正是"三个非共线点 → 一个方向"的来源。§8.3 给出"一组正交基 + 一个原点"这一步：每个"残基坐标系（frame）由三个正交向量（三个方向）定义，可以用一个旋转矩阵和一个平移来参数化"，并把它认成 $SE(3)$ 的元素；同节把 $SE(3)$ 与"只含 proper 操作、行列式 $+1$"的旋转对应起来，手性一侧则由 §8.4 的"FAPE 能处理**手性（chirality）/镜像反射**"点出。**缺口**：两节都没有写出一般构造步骤——哪个点当原点、第一个基向量取哪条点差并归一化、第二个基向量如何对第三个点差做正交化、第三个基向量取 $\pm$ 叉积如何决定框架手性。导读按原文能支撑的"三点定平面 → 平面给法向 → 正交基 + 原点 = 框架"写，未代写 Gram–Schmidt 公式（见下"覆盖缺口"）。

- **相对位置与相对变换（把邻居坐标变换到当前残基框架下）**：由同一篇 §8.4 的 FAPE 描述与 §8.1 的残基气体描述覆盖。§8.4 写的是"取**每一个残基框架**，把它**对齐到它在天然结构中的位置**，然后在某个邻域内计算**其他每个点的误差**"，并解释成"对齐了你关注的残基后，看看周围每个点偏了多少"——把邻域内的点搬到当前残基的框架里再比较，就是相对变换的用法；同节还说明这种表示只需"分解成 Cα 的平移和一个 $3\times 3$ 旋转矩阵"，即"原点 + 旋转"两件东西就够描述一个相对变换。§8.1 则从对象一侧说明为什么必须用相对量：残基气体"把**每个残基当作一个可以相对于彼此独立移动的对象**"，被预测和更新的量是每个残基自己的框架，而不是一组全局绝对坐标。**缺口**：原文没有写出 $x^{\text{local}}_j = R_i^{\top}(x_j - t_i)$ 这一行显式式子，也没有说明"同一个邻居在 $i$ 的框架与在 $j$ 的框架里得到两组不同局部坐标"这一对照。作为反面对照，[《几何深度学习（五）：EGNN 等变性几何图神经网络》](../../4.1_等变网络/4.1.2_等变消息传递：特征更新与坐标更新/几何深度学习（五）：EGNN%20等变性几何图神经网络.md) §4.1 用的是**不带框架**的相对位置 $r_{ij}=x_i-x_j$：它只做向量减法，方向仍随全局旋转一起转，因此需要靠坐标分支的等变性把旋转吸收掉；本节讲的框架路线则把旋转吸收进框架本身，让局部坐标在全局旋转下不变。

- **在残基几何网络中的用途（IPA 的 query/key 几何特征、FAPE 的框架对齐）**：由同一篇 §8.2 与 §8.4 覆盖。§8.2 说明 IPA 让"**配对表示、单链表示和当前主链坐标系**三者相互交流"：单链表示"生成 query 和 key，与 3D 位置比较，判断哪些残基应该相互交流、并**相对移动**"，配对表示"带着它的结构假设来更新这些注意力亲和度"，最终每个残基"知道它应该对哪个残基关注多少"；同一节还说明框架是被预测的对象——每个 block 里"先做 IPA 更新单链表示，再据此**预测旋转和平移**来更新主链坐标系"，8 个 block 反复把残基从原点展开。§8.4 说明 FAPE 一侧的用途：因为"一切都用**框架（frame）**来参数化"，损失就以框架为单位对齐后再算邻域误差，并因此获得对**手性/镜像反射**的处理能力与更低的内存占用。**缺口**：原文只写到 query/key"与 3D 位置比较"，没有点明这些 query/key 是**在各自残基框架里表示的三维点**（point attention 的几何特征），也没有展开 value 的几何分支；这一层属于 4.1.3 与 P01 的 IPA 推导范围。

- **与 4.1.3 的分工**：4.1.3 的博客在文首"本节定位"里已经划界——它的主线是第八章（残基气体、IPA、$SE(3)$、FAPE），"据此说明局部坐标框架如何构造几何注意力，以及框架选择对等变性的影响"，并明确"P01 §2.2.4 的 IPA 推导不在本节重复"。因此本节只回答两个问题：一组正交基怎么从三个点长出来、邻居坐标怎么搬进这组基；IPA 的注意力打分怎么把点距离、配对表示与单链表示合成一个权重、$SE(3)$ 不变性与等变性的完整论证、FAPE 的逐项求和与截断，全部归 4.1.3，本节不重复推导。

## 边界提醒

- 本节讲的是**框架**（一组正交基 + 一个原点），不是 3.1.2 讲的**全局变换**。全局旋转/平移作用在所有框架上、把每个框架整体搬走；局部框架变换是把一个点搬到某个框架的基底下表示。两者的关系是：全局变换下局部坐标不变，这正是框架路线想要的性质。
- 三个点必须**非共线**才有唯一平面与法向；共线时平面不唯一，框架退化。原文只以 N–Cα–C 这一实例出现，没有讨论退化情形，导读不补。
- 框架的**手性**（第三个基向量取 $+\mathbf{e}_1\times\mathbf{e}_2$ 还是取反）决定框架是右手系还是左手系，也决定框架能否区分对映体；反射下的行为按 3.1.2 §五–§七的表处理，本节不展开。
- 分子内部几何量（距离、键角、二面角）本身不依赖框架，属于 3.2.1；标量与向量特征在框架内如何各自变换，属于 3.2.3；高阶方向表示属于 3.2.4。
