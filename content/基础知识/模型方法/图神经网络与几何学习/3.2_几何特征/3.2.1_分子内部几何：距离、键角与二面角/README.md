# 3.2.1 分子内部几何：距离、键角与二面角 · 导读

本节要建立的是"同一分子的内部几何量"这张对照表：距离、键角、二面角各自由几个原子定义、分别对应几个自由度，它们在旋转平移下如何不变，二面角为什么是周期量，以及只靠这些内部量能否唯一确定一个三维结构。分工上，这些量作为标量特征进入网络的部分由 3.2.3 处理，"把方向编码成高阶特征"由 3.2.4 处理；本节只讲内部几何量本身。

## 学习目标覆盖

- **距离、键角、二面角各自的定义与自由度（同一分子比较）**：定义与"由几个原子确定"落在 3.1.2 §三 与《二面角转一圈回到原处》§一–§二："两原子间距离、三原子间键角、四原子间二面角"；四原子定义的必要性在《坐标生成输出的是一个构象集合，不是一张正确结构》§4.1 说得更细——"某个键的扭转角是一个二面角，需要为键两端的每个原子各选一个邻居来定义"，所以同一条键可以选出不同的四个点、得到不同的 $\tau$ 与 $\tau'$（§4.2）。二面角的 $2\pi$ 周期、$[0,360^\circ)$ 与 $(-180^\circ,180^\circ]$ 两种区间约定，以及 $3N-6$ 的构造性计数，在《二面角转一圈回到原处》§三–§五。参考值与偏离的算法在《结构合法性怎么判》§二：每条键与每个角都有理想值，模型值与之相减再除以标准差得到 sigma，界面统计超过 4σ 的离群条目；§八 的"虚拟二面角"则说明二面角也可以用不直接相连的四个原子（相邻 Cα、相邻羰基）来定义。自由度的比较落在《坐标生成输出的是一个构象集合，不是一张正确结构》§3.1–§3.2：一个平均 44 原子的类药分子，外在坐标是 $3N=132$ 维，而柔性只落在可旋转键的扭转角上、不到 8 维；键长、键角与环的构象被当作"局部结构 $L$"、交给化学信息学方法预测。也就是说，同一分子可以用 $3N$ 个笛卡尔坐标描述，也可以只用一组内部几何量描述，后者维数远低于前者。

- **刚体变换不变性**：由《旋转与平移只换参考系，反射会翻转手性》给出。§三 明确"旋转改变的是每个原子的坐标和分子的朝向……它不改变任何**内部**几何量：两原子间距离、三原子间键角、四原子间二面角，在旋转下都不变"；§四 说明平移"朝向不变，内部几何量全部不变，能量也不变"；§七 的逐项表把距离、键角、带符号二面角三行都标成"旋转：不变 / 平移：不变"。同一结论在 4.1.2 的《几何深度学习（五）：EGNN 等变性几何图神经网络》§1.1 用"标量不具备方向性"重述，§3.2 则给出距离的坐标写法：取 $i$、$j$ 坐标之差得到方向向量 $r_{ij}$，再用其模长表征两点间距离。《结构合法性怎么判》§二 的理想值与 sigma 偏离也都是内部量之间的比较，与结构在空间中的朝向无关。

- **角度周期性**：二面角的 $2\pi$ 周期性由《坐标生成输出的是一个构象集合，不是一张正确结构》§3.3 直接给出——"扭转角从 $0$ 到 $2\pi$，而 $2\pi$ 与 $0$ 是同一个角，所以 $m$ 个扭转角构成的空间是一个混合环面 $\mathbb{T}^m$，不是欧几里得空间"，术语表把环面解释为"多个 $0$ 到 $2\pi$ 周期变量构成的空间，$2\pi$ 与 $0$ 是同一点"。同一件事在《二面角转一圈回到原处》§三–§四 与《结构合法性怎么判》§五 有两个侧面：前者直接给出 $2\pi$ 周期与 $[0,360^\circ)$、$(-180^\circ,180^\circ]$ 两种区间约定的互换；后者把主链 $\phi,\psi$ 画成参考分布等高线图、按分位数判离群，这种图本身就建立在二面角是 $360^\circ$ 一周期的量之上。需要注意：这一条只覆盖"二面角是周期量、周期为 $2\pi$"；$[0,360)$ 与 $(-180,180]$ 两种区间约定如何对应、以及键角（取值 $[0,\pi]$）为什么不是周期量，现有材料里都没有明写，见下文缺口 1。

- **重建歧义**：现有材料给出的是"内部几何不足以定死三维结构"的两条证据，而不是完整的重建定理。第一条来自 3.1.2 §五：反射"保持距离和键角"，但"带符号的二面角会变号"；§六.1 进一步说明对映体"有完全相同的 2D 图连通性（同构），差别只在三维排布"，"唯一能互换它们的方式，是把三维坐标对着一个镜面反射"；§七 的表把距离、键角标成反射下不变、带符号二面角标成反射下变号。合起来就是：只用距离和键角这套内部量，镜像结构与原结构完全无法区分，必须补上带符号的二面角才能定手性。第二条来自《坐标生成输出的是一个构象集合，不是一张正确结构》§4.3：底层能量宇称不变，"同一分子图、同一局部结构的两个镜像能量几乎完全相同"，因此模型输出必须宇称等变；§4.2 又指出固定局部结构后 $\Delta\tau=\Delta\tau'$，即扭转角的具体数值依赖四个点的选法、只有变化量是确定的。这两处支持"内部几何 → 坐标"不是一一对应，但都没有写出重建步骤（Z-matrix、距离几何）或"内部坐标数 $=3N-6$、重建唯一到刚体变换与镜像"这样的表述，见下文缺口 2。

- **与 3.2.4 的分工**：3.2.4 的博客在 SCQA 里已经划界——它从"上一节（3.2.3）把几何网络里的特征分成两类"接着往下走，起点是"一个向量只有 3 个数……但分子里真正要描述的是'从这个原子看出去，每个方向上有多少邻居'"。也就是说，3.2.4 处理的是**把方向写成特征**：球谐 $Y_l^m$ 作为分阶基、第 $l$ 阶有 $2l+1$ 个分量、按 $l$ 分块构成不可约表示、不同阶用张量积与 Clebsch–Gordan 系数耦合。本节处理的是**内部几何量本身**：距离、键角、二面角这三个旋转平移下不变的标量，以及它们的定义、自由度、周期性与重建歧义。本节不引入球谐、不讨论阶与宇称、不推导张量积；3.2.4 也不重复距离/键角/二面角的定义与不变性论证。

## 边界提醒

- 本节说的"内部几何量"专指由 2、3、4 个原子确定的距离、键角、二面角，不含局部坐标框架（3.2.2）、不含标量/向量特征的类型划分（3.2.3）、不含球谐（3.2.4）。
- 反射下的完整行为（手性、对映体、$E(3)$ 与 $SE(3)$ 的取舍）属于 3.1.2 与 4.1.1；本节只用到"距离、键角反射不变，带符号二面角反射变号"这一条来支撑重建歧义。
- 4.2.2 的《结构合法性怎么判》主线是"如何判结构合法性"，给出理想值、sigma、clash 这些量化参考，但没有以"内部几何量"为组织线索；本节只从它取 §二、§五、§八 的判据。力场能量项与 GROMACS 参数表属于 4.2.2 的力场主线，不在本节展开。

## 覆盖缺口

1. **键角与二面角的坐标公式未写出**：4.2.2 给的是理想值与 sigma 偏离，3.1.2 与《二面角转一圈回到原处》给的是“三原子/四原子”的计数定义与“四原子确定的角度、反射下变号”，都没有 $\arccos$、$\operatorname{atan2}$ 形式的显式定义，也没有“二面角符号由哪三个向量决定”的推导。本节的定义停在“由几个原子确定、量的是什么”这一层；需要显式公式时再补。
2. **重建只到流程与歧义，未做距离几何的完整求解**：NEW 博客给出 Z-matrix 的逐原子重建流程与 $+\phi/-\phi$ 的镜像歧义，但没有展开距离几何（distance geometry）的矩阵求解与嵌入算法；本节不把“重建”扩展成完整算法课。
