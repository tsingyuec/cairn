# 4.1.1 E(3)、SE(3) 等变及反射约束的差异 · 导读

本节只做一件事：把"等变"这个词前面的群名说清楚。$E(3)$ 与 $SE(3)$ 的差别不在网络多深、特征多高阶，而在**允不允许反射**；而允不允许反射，等价于**模型能不能区分一个分子和它的镜像**。变换本身的分类、手性中心的判据、逐项物理量的行为表由 3.1.2 承担；EGNN 的消息与坐标更新怎么实现等变由 4.1.2 承担；局部坐标框架与 IPA 的构造由 4.1.3 承担。本节不重复这三处，只把"选哪个群"这件事讲成可判断的规则。

## 学习目标覆盖

- **$E(3)$ 与 $SE(3)$ 的允许变换差在哪（是否含反射 / improper rotation）**：由三处拼成。①**$E(3)$ 一侧**：《几何深度学习（五）：EGNN 等变性几何图神经网络》§2.1「E(3)：对旋转、平移、反射都等变」写明 EGNN 的等变对象是"针对**旋转、平移、反射**三类变换"，"在三维欧几里得空间里对平移、旋转、反射都等变，一般记作 **E(3)**"，模型名 E(n)-equivariant GNN 就由此而来。②**$SE(3)$ 一侧**：《第04讲：用 AlphaFold2 / OpenFold 做结构预测》§8.3「SE(3)、不变性与等变性」把 $SE(3)$ 定义为"每个残基坐标系由三个正交向量定义，**可以用一个旋转矩阵和一个平移来参数化**——这正是 SE(3) 的定义"，并指出它是一个流形；旋转矩阵（而非任意正交矩阵）这一措辞已经排除了反射，但该段**没有把这一点挑明**，需要靠 3.1.2 的判据补上。③**判据本身**：《旋转与平移只换参考系，反射会翻转手性》§一 的对照表把平移、旋转归为"不翻转手性"，把反射、反演 $i$、improper rotation $S_n$ 归为"翻转手性"；§五 给出反射的矩阵形式 $M=\mathrm{diag}(1,1,-1)$、$\det M=-1$，并点明"行列式为 $-1$，这就是 improper 的含义"。三处合起来才是完整结论：$E(3)$ 允许 $\det=\pm1$ 的正交部分，$SE(3)$ 只允许 $\det=+1$ 的 proper rotation。**同一差别的模型侧证据**见 EGNN §3.4「TFN：高阶可导向特征，只差'反射'」——"EGNN 对**旋转、平移和反射**都等变，而 TFN 只对**旋转和平移**等变，没有对反射的对称性"，这正是 $E(3)$ 等变模型与 $SE(3)$ 等变模型的分界，也是本节最直接的一段对照。

- **反射约束对分子手性的影响**：分四步。①**手性是什么**：3.1.2 §六.1「手性的定义与手性中心」用四面体手性说明——一个碳连四个互不相同的基团，空间排布有两种、互为镜像，两者"2D 图连通性完全相同，差别只在三维排布"；无论怎么旋转分子或中心碳碳键都**不能**互换，唯一互换方式是对着镜面反射，这对分子叫**对映体**。§六.2 补上群论判据：手性分子不能有反演中心 $i$ 或 improper axis $S_n$，因为二者都含翻转成分。②**反射为什么改变化学身份**：3.1.2 §五 直接给出后果——"反射一个手性分子，会把它的手性中心整个翻过来，等于改变了分子身份"，因此"对反射不变的模型因此也对**手性**不变，无法区分对映体"。③**模型侧后果**：3.1.2 §八 把模型分三档，其中"$E(3)$ 不变的 3D 模型：因为对反射也要求不变，它们'从根本上无法区分镜像对映体'"；同节的 SphereNet 实验还给出反向证据——把构象对着镜面反射（手性真的翻转了），$E(3)$ 不变的 SchNet 与 DimeNet"完全被这个操作骗过，仍然认为它们是同一个东西"。④**任务侧后果**：AF2 §8.4「FAPE：为『残基坐标系』量身定做的损失」指出 FAPE 相比 RMSD 的优势之一是"能处理**手性（chirality）/镜像反射**"——结构预测必须把手性当正确答案的一部分，损失函数若对镜像无差别，模型输出对映体也不会被惩罚。这一条把"反射约束"从表示层拉到了监督层。

- **任务何时需要 $E(3)$ 等变、何时只需 $SE(3)$ 等变**：判据由 3.1.2 §七 与 §八 给出，EGNN 与 AF2 各提供一个实例。①**量本身是否依赖手性**：3.1.2 §七 的表逐项列出——能量是标量，"对三类变换都不变"，"两个对映体在非手性环境里的能量也是简并的"；原子间距离、键角对反射不变；带符号二面角在反射下**变号**；旋光符号在反射下翻转；对映体结合亲和力在反射下"换到另一个对映体"。所以**只关心标量能量/性质回归**时，$E(3)$ 不变就够，甚至更省事——EGNN §2.1、§3.5 正是这条路：把距离直接拼进消息，绕开球谐与高阶特征的开销。②**任务是否要区分对映体**：要区分就必须保留对手性敏感的量，即不能对反射不变，此时 $SE(3)$（或更弱的 proper 旋转对称）才是正确约束；3.1.2 §八 明确"$SE(3)$ 不变的 3D 模型：不要求反射不变，原则上能区分对映体"，但同时警告它"对构象变化同样敏感，容易把'构象不同'误判成'手性不同'"。③**生成/结构预测一侧**：AF2 §8.4 的 FAPE 是现成例子——输出是三维结构、手性是对错的一部分，所以损失必须对镜像敏感；这与"能量回归只需不变"形成对照。归纳成一句可操作的话：**输出是标量且标签对反射不变 → $E(3)$ 等变足够；输出是结构/手性敏感性质 → 必须至少 $SE(3)$，不能把反射打包进对称群。**

- **与 4.1.2 / 4.1.3 的分工**：本节只讲**变换群与反射约束**，不讲怎么实现。EGNN 博客开头的定位行已写明"E(3)/SE(3) 的允许变换与反射约束留给 4.1.1"，其 §四、§五（消息 $m_{ij}$、坐标分支 $\hat m_{ij}$、双分支聚合、$h$ 不变与 $x$ 等变的证明）是 4.1.2 的内容——那里回答"给定 $E(3)$，网络怎么做到等变"。3.1.2 §八 末段同样划界："本节只讨论**变换本身**和**哪些量该保持**"，并注明"$E(3)$ 与 $SE(3)$ 等变模型的系统对照是 4.1.1"。AF2 §8.3 的残基框架、§8.2 的 IPA 与 §8.4 的 FAPE 构造属于 4.1.3——那里回答"局部坐标框架怎么搭出几何注意力、框架选择如何影响等变性"。本节引用这三处时只取"允许哪些变换""哪些量该保持"的结论，不复述消息公式、不改写 IPA 推导。

## 边界提醒

- $E(3)$ / $SE(3)$ 在这里指**坐标变换群**，不是"模型复杂度等级"。$SE(3)$ 等变并不比 $E(3)$ 等变"更高级"，它只是约束更弱、保留了手性自由度；选错的代价是任务层面的（该区分对映体时区分不了，或不该区分时把构象差异误读成手性差异）。
- 反射、反演 $i$、improper rotation $S_n$ 三者都翻转手性，但只有反射是 $E(3)$ 里与旋转、平移并列的生成元；$i$ 与 $S_n$ 可由旋转加反射复合得到。判据用 $i$ 与 $S_n$，是因为它们描述的是**分子自身的对称元素**，与"我们能施加哪些变换"是两个问题（3.1.2 §二 专门区分了对称元素与对称操作）。
- 节点顺序的置换等变（2.2.1）与坐标的 $E(3)$/$SE(3)$ 等变形式相似但对象不同，不要互相套用。

## 覆盖缺口

1. **AF2 §8.3 没有明说 $SE(3)$ 排除反射**：该段只说 $SE(3)$ 由"一个旋转矩阵和一个平移"参数化，靠"旋转矩阵"隐含 $\det=+1$；它没有把 $E(3)$ 与 $SE(3)$ 并排对比，也没有出现"反射"字样。本节导读中"$SE(3)$ 不含反射"这一步，实际依据是 3.1.2 §五 的 $\det=-1$ 判据与 EGNN §3.4 的 TFN 对照，AF2 §8.3 只提供 $SE(3)$ 的正面定义。若要把这一条写成原文结论，需另找明确讨论 proper/improper 的素材。
2. **"生成任务必须 $SE(3)$"没有成文判据**：3.1.2 §八 给的是模型三档与"$SE(3)$ 易把构象差异误判为手性差异"的警告，AF2 §8.4 给的是 FAPE 处理手性的单个实例；两处都没有"结构生成/坐标输出任务一律要求对反射敏感"这样的显式规则。导读中这一条是按 §七 的量表与 §8.4 的损失设计归纳的，不是原文结论，写作时须标明是归纳。
3. **$E(3)$ 与 $SE(3)$ 等变的系统对照**：README 把"系统对照"划给本节，但现有三篇博客只提供零散对照（EGNN vs TFN、SchNet/DimeNet vs SphereNet、FAPE vs RMSD），没有一篇把两组模型按群逐项列表比较。本节导读据现有段落组织，不补造对照表；若后续需要完整对照，应另采素材。
