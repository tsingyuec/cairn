# 序列建模与基础模型

编号：M02 · 类型：模型基础 · 目录规模：49 个小节（三级叶子节点，少于 100）。

**知识主线**：序列表示 → 上下文建模 → 自监督预训练 → 条件生成与迁移。

**范围与边界**：Transformer 是核心但不是序列模型的唯一形式；生物 token 的具体含义留给应用专题。

**前置知识**：[M01 §1.1.1 向量、矩阵、张量与维度](../统计学习与科学评估基础/README.md#m01-1-1-1)、[M01 §2.1.2 多层感知机（MLP）：线性层、激活函数与任务头](../统计学习与科学评估基础/README.md#m01-2-1-2)；仅作为最低起点。 其余所需基础在下方章节使用处以 `[复用]` 小节编入，不要求通读任何上游脉络。

**组织与素材策略**：以可独立解释的一条计算或推断链为单元。先满足基础，再读模型；一个张量/参数不是一个独立课程。

> 小节按可独立理解和验收的机制、推理或判读任务划界。知识完整性优先；1–3 篇只是素材预算，同一长视频可跨小节引用，不能为减少重复采集而合并独立机制。

> 自有任务进度：`[WAITING]` 待处理 · `[PROCESSING]` 已认领 · `[DONE]` 已验收 · `[ABORT]` 终止。处理规则见项目 skill 的 `processing.md`。

> 内容构成：37 个自有写作小节，12 个通用复用小节。`[REUSE]` 是课程内容类型，不是进度状态；计入本脉络小节规模，但不另建正文或认领任务。

## 2 从局部模式到长程依赖

<a id="m02-2-1"></a>

### 2.1 经典序列网络

### 2.2 注意力与 Transformer

- 2.2.1 向量相似性：内积、夹角与距离 <a id="m02-2-2-1"></a> [REUSE](../统计学习与科学评估基础/README.md#m01-1-1-2)

- 2.2.2 查询、键、值与自注意力 <a id="m02-2-2-2"></a> [WAITING]
  - 学习目标：说明卷积核、局部感受野与权值共享；判断卷积层如何提取序列模式；避免与 2.2.3 多头注意力的关系混淆。
- 2.2.3 多头注意力：QKV 投影、分头与输出合并 <a id="m02-2-2-3"></a> [WAITING]
  - 学习目标：连起 QKV 投影、分头和合并；不拆 query/key/value 各自开课。
- 2.2.4 Transformer 前馈子层：逐位置非线性与通道变换 <a id="m02-2-2-4"></a> [WAITING]

- 2.2.5 残差连接与层归一化：信息通路、尺度与深层训练 <a id="m02-2-2-5"></a> [WAITING]

- 2.2.7 交叉注意力：条件注入、查询来源与序列对齐 <a id="m02-2-2-7"></a> [WAITING]
  - 学习目标：区分查询与键值的来源，以条件序列生成解释信息流；不重新讲一套 QKV 数学。
- 2.2.8 因果注意力：掩码、训练并行与逐步生成 <a id="m02-2-2-8"></a> [WAITING]
  - 学习目标：围绕信息可见性读通一次训练和生成。

## 3 用无标签数据学习

<a id="m02-3-1"></a>

### 3.1 自监督目标

- 3.1.1 似然、对数似然与最大似然估计 <a id="m02-3-1-1"></a> [REUSE](../统计学习与科学评估基础/README.md#m01-1-2-5)

- 3.1.2 信息量与散度：熵、交叉熵和 KL <a id="m02-3-1-2"></a> [REUSE](../统计学习与科学评估基础/README.md#m01-1-2-6)

## 5 大规模序列建模的边界

<a id="m02-5-1"></a>

### 5.1 长上下文的代价

- 5.1.1 注意力计算复杂度：序列长度、计算量与内存代价 <a id="m02-5-1-1"></a> [WAITING]
  - 学习目标：从注意力矩阵形状推导长度带来的代价，区分训练、解码及缓存；不讲 GPU 内核开发。
- 5.1.2 高效注意力：精确分块计算与稀疏近似 <a id="m02-5-1-2"></a> [WAITING]
  - 学习目标：比较精确分块和改变可见性的稀疏方法，指出哪些改变计算过程、哪些改变模型假设。
- 5.1.3 状态空间模型：隐状态更新、卷积形式与长程记忆 <a id="m02-5-1-3"></a> [WAITING]
  - 学习目标：在离散递推和序列卷积之间建立对应，解释状态维度与记忆，不推导控制理论全集。
- 5.1.4 选择性状态空间模型：输入依赖与扫描计算 <a id="m02-5-1-4"></a> [WAITING]
  - 学习目标：用选择性状态更新解释内容依赖的记忆保留，区分它与固定线性系统及标准注意力。
- 5.1.5 长卷积与混合序列架构 <a id="m02-5-1-5"></a> [WAITING]
  - 学习目标：用 Evo 类模型的背景比较路线，不穷举所有新架构。
- 5.1.6 预训练语料：来源构成、去重与训练—测试污染 <a id="m02-5-1-6"></a> [WAITING]
  - 学习目标：说明预训练语料的来源与组成；判断序列去重、同源聚类与时间截断的必要性；识别训练—测试污染；把语料质量与下游评测可信度联系起来。
- 5.1.7 预训练规模：参数量、数据量与计算预算的权衡 <a id="m02-5-1-7"></a> [WAITING]
  - 学习目标：说明规模、数据与算力的相互约束，判断扩大模型是否仍有收益。

<a id="m02-5-2"></a>

### 5.2 可信性

- 5.2.1 序列同源、结构相似与时间切分 <a id="m02-5-2-1"></a> [REUSE](../统计学习与科学评估基础/README.md#m01-5-1-1)
  - 学习目标：区分序列同源、结构相似与时间切分三种隔离依据；判断训练/测试划分是否泄漏同源信息；把评估协议与真实泛化能力联系起来。
- 5.2.2 模型验证：基线对照、消融实验与外部验证 <a id="m02-5-2-2"></a> [REUSE](../统计学习与科学评估基础/README.md#m01-5-2-1)
  - 学习目标：说明序列模型评测的基线、消融与外部验证；判断随机基线、非神经基线与任务专用基线的差别；把评测协议与模型声明对应起来。
- 5.2.3 似然、困惑度与生物适应度的区别 <a id="m02-5-2-3"></a> [WAITING]
  - 学习目标：区分模型似然、困惑度与实验适应度，说明概率分数不能直接当功能证据。
- 5.2.4 概率校准与可靠性曲线 <a id="m02-5-2-4"></a> [REUSE](../统计学习与科学评估基础/README.md#m01-4-2-1)
  - 学习目标：说明校准曲线与可靠性的含义；判断似然分数能否当概率使用；把校准与 5.2.3 的困惑度、5.2.5 的适用域区分开。
- 5.2.5 模型适用域：分布外输入与拒绝预测 <a id="m02-5-2-5"></a> [REUSE](../统计学习与科学评估基础/README.md#m01-4-2-4)
  - 学习目标：说明适用域、分布外输入与拒绝预测；判断低覆盖序列为何不能外推；把适用域与 5.2.4 的校准、5.2.2 的外部验证联系起来。
