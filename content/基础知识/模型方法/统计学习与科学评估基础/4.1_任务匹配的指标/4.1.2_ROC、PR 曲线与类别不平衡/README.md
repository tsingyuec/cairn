# 4.1.2 ROC、PR 曲线与类别不平衡 · 导读

本节用三篇互补素材，把"阈值扫描"这一个动作在两条曲线上走完：先在 ROC 上把扫描机制和 AUC 讲透，再学怎么读 PR 曲线，最后用低事件率的实例说明两条曲线为什么会在不平衡数据上给出不同结论。

## 目标覆盖

- **阈值扫描的机制**：《ROC 曲线与 AUC：从阈值扫描到曲线下面积》§三 把绘制流程拆成五步（预测概率 → 概率排序 → 逐个概率作阈值 → 数 TP/FP/TN/FN 算 TPR/FPR → 连点）；§四 用 15 个样本、15 个阈值手算出完整坐标表，并指出"阈值下降等价于一次多放一个样本进正类"，所以 TPR 与 FPR 只增不减。
- **AUROC 的定义与判读**：同篇 §一 给出 TPR = TP/(TP+FN)、FPR = FP/(FP+TN)，点明两个分母分别是真实正类与真实负类；§二 用理想 L 形、对角线、对角线以下三种极限定出曲线形状的含义；§五 把 AUC 定义为曲线下面积并给出 0.5/1 的判读规则，§七 用手算三块长方形（0.8928）与 `roc_auc_score`（0.892857）对账。
- **AUC 的适用边界**：同篇 §六 给出两条代价——只看排序不看概率绝对准确性（所有得分同除常数后 AUC 不变）、极端不平衡（正 10 / 负 1000）时会高估，并明确指向 PR 曲线。
- **PR 曲线的读法与比较**：《PR 曲线怎么读：包住、平衡点与 F1 三种比较法》§一 说明每个点对应一个阈值，§二 给出观察法（完全包住、允许重合不允许交叉）及其"固定 P 比 R / 固定 R 比 P"两条等价判据，§三 用平衡点法处理交叉情形，§四 推出平衡点的实质是 FP = FN，§五 用调和平均给出 F1 = (1+β²)PR/(R+β²P) 并说明 β 必须由问题决定。
- **AUROC 与 AUPRC 的差异（类别不平衡）**：《低事件率下 AUC 会高估：PR 曲线与 AP 的随机基准》§一 解释 FPR 的分母含全部阴性样本、阳性稀少时被摊薄；§二 指出 PR 的两个分母都不含 TN；§三 给出 AP 的定义与关键差别——ROC 的随机基准固定 0.5，AP 的随机基准等于事件发生率；§四 用同一模型 AUC = 0.853、AP = 0.263、基线 4% 的实例说明"两个数字都对，只是基线不同"；§五 给出"报 AP 必须同时报基线、不要用 0.5 衡量 AP"两条判读习惯。

## 阅读顺序

1. 先读《ROC 曲线与 AUC》，把"排序 → 逐阈值数格子 → 连点 → 求面积"这条链路走通，AUC 的"阈值无关"才有依据。
2. 再读《PR 曲线怎么读》，把同一套阈值扫描换到（R, P）平面上，学会在曲线有交叉时怎么判定优劣。
3. 最后读《低事件率下 AUC 会高估》，把两条曲线的分母差异落到"为什么阳性稀少时结论不同"，并记住 AP 的基线不是 0.5。

## 边界与缺口

- 混淆矩阵四格、精确率/召回率、MCC 的定义与"分母是谁"的判读规则在 4.1.1，本节不重复；本节只使用这些量。
- 多类聚合（macro/micro/weighted）留给 4.1.3；回归误差指标留给 4.1.4。
- 概率校准与可靠性曲线留给 4.2.1——本篇只指出"AUC 不反映概率绝对准确性"，不展开校准方法。
- 阈值—代价决策留给 4.2.2；本篇的阈值扫描只用于构造曲线，不讨论"该选哪个阈值"。
- 三篇素材的例子分别是合成数据（15 个样本）、通用二分类概率与一个临床预测队列，没有生物信息专有实例；迁移到本库的稀有事件任务（罕见位点、低频突变、稀有细胞状态）时须自行核对事件率。
- 第三篇视频只有 2 分半，且无平台字幕，文稿由本地语音转写后逐句校对；其"事件率 3.92%、AUC 0.853、AP 0.263"来自视频演示的队列，未独立复核原始数据。
- AUPRC 的积分/插值实现细节（如阶梯式 AP 与梯形插值的差别）视频未涉及，本节不作验收点。
