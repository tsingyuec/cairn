# 4.1.1 混淆矩阵、精确率、召回率与 MCC · 导读

本节用三篇互补素材，围绕**同一张混淆矩阵**把阈值指标讲完：先建表，再换分母，最后换指标。

## 目标覆盖

- **混淆矩阵与四个格子**：《7分钟搞懂：敏感性、特异性、阳性预测值、阴性预测值！》§1 从金标准（真实标签）出发，把"真相 × 判断"交叉成 TP / FP / TN / FN，并强调格子名里的"阴/阳"指预测结果而非真相（FN 的人其实有病）。§6 用"哭脸笑脸 + 红圈"图把四个格子放回人群。
- **精确率与召回率**：《【小萌五分钟】机器学习｜模型评估：准确率 Accuracy 精确率 Precision 召回率 Recall F1值》§2 用图片搜索引擎给出 Precision = TP/(TP+FP)、Recall = TP/(TP+FN)，并点明它们就是诊断试验里的 PPV 与敏感性——同一公式、两套名字。§3 用"把所有图片都返回"的极端例说明两者此消彼长；§4 用调和平均解释 F1 的"偏科重罚"与 F-β 的偏重调节。
- **分母决定指标含义**：《7分钟搞懂》§2–§5 把四个指标分成两组视角：分母在真实人群（敏感性/特异性，回答"查全"）与分母在预测结果（PPV/NPV，回答"查准"）。写公式前先问"分母是谁"，是本节最可迁移的一条判读规则。
- **同一结果上的阈值效应**：《The Definitive Guide to the Matthews Correlation Coefficient》§4 在平衡分布上扫描阈值，recall 单调下降、precision 上升、F1 在两分布交叉点取最大；§5 换成 1000:100 的不平衡分布后，准确率在阈值接近 1 处虚高（全判负类即可白拿高分），F1 与 MCC 则被抑制。
- **MCC**：同篇 §2 给出 MCC = (TP×TN − FP×FN) / √((TP+FP)(TP+FN)(TN+FP)(TN+FN))，分子是"一致项乘积减错误项乘积"，分母是恒正的归一化常数；§3 用三个极端矩阵定出 −1 / 0 / +1；§6 给出适用判据——正负类同等重要、四类错误权重相同；惯用准确率的场合应把两者都算出来对照。

## 阅读顺序

1. 先读《7分钟搞懂》，建立"金标准 × 检测 → 四格 → 两种分母视角"的表结构。
2. 再读《小萌五分钟》，把准确率、精确率、召回率、F1 挂到同一张表上，并看清精确率/召回率的拉扯。
3. 最后读 MCC 指南，把"移动阈值 → 指标曲线"和"不平衡下准确率失效"接上，得到指标选择判据。

- 多类聚合（macro / micro / weighted）留给 4.1.3。《小萌五分钟》§5–§6 提到 macro/micro 两条路线与"micro 三值等于 accuracy"，此处仅作衔接，不作本节验收点。
- 概率校准（4.2.1）、阈值—代价决策（4.2.2）、回归误差指标（4.1.4）均不在本节。
