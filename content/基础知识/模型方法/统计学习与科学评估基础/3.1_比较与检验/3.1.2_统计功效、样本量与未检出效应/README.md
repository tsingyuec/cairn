# 3.1.2 统计功效、样本量与未检出效应 · 导读

本节与 3.1.1 共用同一篇素材《显著不等于效应大：效应量的度量、阈值与样本量陷阱》。按“共享博客只存一份”的约定，正文保留在 3.1.1 目录，本节不重复存放；本节自有正文是《单细胞扰动实验的重复怎么设：配对取材、混样与细胞捕获数》。

## 目标覆盖

- **统计功效是什么**：共享博客 §6.1 把功效定义为“有效应时能测出来”的概率；§6.2 用四个旋钮（效应量、样本量、α、检验设计）解释功效由谁决定。
- **样本量如何影响结论**：共享博客 §6.3 说明低功效的三重代价——假阳性、假阴性、效应量系统性高估；§6.4 给出事前功效分析反解样本量的思路；§7.5 用“每组 39 人”的完整例子走一遍从原文 t 值到样本量的计算。本节自有正文则从实验设计侧说明重复数、混样与细胞捕获数如何决定能否看见效应。
- **区分“未检出”与“不存在效应”**：共享博客 §6.3 指出小样本“测不出来”不等于没有效应；本节自有正文 §3.3 明确“阴性结果说明不了‘没有效应’，只说明‘没看见’”，并用重复数—功效表说明温和扰动在 3 个重复下功效仅约 17%。

## 阅读顺序

1. 先读本节自有正文《单细胞扰动实验的重复怎么设》，建立“重复数—混样—捕获数”如何影响可检出性的实验设计直觉。
2. 再读共享博客的 §6.1–6.4 与 §7.5，把功效、样本量与阴性结果的解释补齐。
3. 需要效应量与置信区间的语言时，回到 3.1.1 的同一篇 §2–§5。

## 边界与缺口

- 本节没有展开等效检验/TOST、非劣性检验、贝叶斯因子或 ROPE；这些是“证明无效应”的形式化方法，现有素材未覆盖。
- 敏感性分析（样本量已定，反求可检出多小的效应）只在共享博客中被提及，未给数值例子；§7.5 是事前样本量计算，不是敏感性分析。
- 共享博客 Table 1 的功效数字来自课件幻灯片，未标原始文献，引用时应注明“课件转引”。
- 单细胞功效模拟工具（muscat/scDD 一类）不在本节范围，留给 P08 的扰动效应分析小节。
