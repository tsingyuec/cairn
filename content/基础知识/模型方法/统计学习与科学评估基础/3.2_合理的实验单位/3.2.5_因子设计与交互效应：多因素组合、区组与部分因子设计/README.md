## 一、三篇自有正文的分工

1. 《全因子试验设计：主效应、交互效应与中心点》是骨架：定义、$2^K$、正交表的均衡性与正交性、交互列、水平数、三种设计的分工、重复与中心点、代码化，最后落到扰动实验。
2. 《组合扰动如何判定真交互——加性基线与协同拮抗》回答「交互效应怎么判」：加性基线是零假设，CI 与等辐射图是判据，单扰动臂不可省。
3. 《小分子药物为什么必须做剂量梯度：量效曲线、EC50 与治疗指数》回答「连续因子怎么取水平」：对数间隔、中段最灵敏、效能与效价的区别、有效浓度与毒性窗口。

三篇合起来是「设计矩阵长什么样、每一项由哪些行估计」。剩下没答的是「这些行够不够」——即功效问题。

## 二、功效由四个量共同决定

共享正文《显著不等于效应大：效应量的度量、阈值与样本量陷阱》§6.1 把功效定义为「效应真实存在时能被检测出来的概率」，即 $1-\beta$；§6.2 用四个旋钮说明它由谁决定：

- **效应量**：要检测的差值折合成几个标准差（Cohen's $d$ 一类）。效应越小，零假设分布与真实分布越靠近，功效越低。
- **噪声/方差**：同样的均值差，合并标准差越大，两条采样分布越胖、重叠越多。因子设计里这一项就是「纯误差」，由重复与中心点估计。
- **样本量 $n$**：$n$ 越大，均值在重复抽样下的分布越瘦，功效越高。讲者的判断是：实践中效应量与 $\alpha$ 都动不了，**$n$ 是唯一容易调的旋钮**。
- **$\alpha$ 与检验设计**：放宽 $\alpha$ 提高功效但抬高假阳性；单尾优于双尾、配对/被试内优于被试间、参数检验优于非参数，都是同一笔 $\alpha$ 与 $\beta$ 的交换。

共享正文 §6.3 补上低功效的三重代价：假阴性变多、假阳性相对变多、**显著结果的效应量被系统性高估**（小样本要达到显著，观测差值必须比真实效应更大）。这一条直接解释了为什么「因子筛选阶段只做一次、报出一个很大的主效应」不可信。

## 三、因子设计里的 $n$ 到底是什么：运行次数与误差自由度

这是本节与 3.1.2 的接口，也是把功效接到设计矩阵上的关键一步。

本节正文 §1.2 说明运行次数是设计矩阵的行数：$K$ 个两水平因子、每种组合做 $r$ 次时，总运行数是 $2^K\times r$（讲者在 §3 末尾也点明「每种组合重复两次就是 $2^K\times 2$」）。§5.1 说明 $r=1$ 时误差无法估计——某一点测到 85，真实均值可能是 84，这一次恰好偏高；§5.2 因此用中心点的 3–5 次重复来估计纯误差。

把这两句话接起来，就是因子设计的自由度账本（这一步是本节对上述素材的推论，视频只讲到「只做一次估不出误差」）：

- $2^K$ 个运行点提供 $2^K-1$ 个自由度给「截距 + 全部主效应与交互效应」，正好被 $2^K-1$ 个效应项占满；
- 所以 $r=1$ 时**残差自由度为零**，没有任何自由度留给误差，F 检验无从做起；
- 每种组合重复 $r$ 次后，残差自由度是 $2^K(r-1)$；只用中心点补误差时，中心点重复 $c$ 次贡献 $c-1$ 个纯误差自由度（$c=3$–$5$ 即 2–4 个）。

由此得到三条判断准则：

1. **先看有没有误差自由度**。$2^3$ 设计只做一次、又不放中心点，就没有可检验的分母；此时「哪个因子显著」这个问题在统计上还没成立。
2. **再看误差自由度够不够支撑你要检的效应**。自由度越少，$t$ 分布尾部越厚，同样的效应量需要更大才能达到显著；这就是「运行次数 → 自由度 → 检验能力」这条链。
3. **最后看重复加在哪里更划算**。完全重复按 $2^K$ 倍成本增长（§5.1 的例子：两因子六水平 64 次、重复三次 192 次），中心点只加 3–5 次就能买到纯误差与弯曲检验；代价是中心点只估计误差、不增加任何因子组合的信息。

## 四、判断样本量的三种问法

共享正文给出了可操作的流程，按问法分三类：

- **事前功效分析（a priori）**：给定想检测的效应量、检验类型、$\alpha$ 与目标功效，反解所需样本量。§6.4 列出四步（定效应量 → 定目标功效 → 定 $\alpha$ 与检验 → 用工具算），§7.5 用一组真实数据走完：$d=0.62$、双尾、功效 0.95 时 `pwr.t.test` 给出**每组 69 人**；换成 $d=0.83$ 则是**每组 39 人**。同一段还给了两条经验规则——样本量不应小于原研究，以及「小望远镜法」按比例放大基准效应。
- **敏感性分析**：样本量已被实验条件锁死时反过来问「这个设计能可靠检出多小的效应」。共享正文在 G\*Power 一节（约 76 分处）区分了这两种分析类型，但未给数值例子。
- **查表估量级**：不想跑工具时，用「效应量 × 重复数 → 功效」的表估个数量级。共享正文《单细胞扰动实验的重复怎么设》§3.3 的 Table 1 就是这种表：效应量 1.25 倍时，3、5、10 个重复的功效分别只有 **17%、25%、44%**；1.5 倍时是 43%、64%、91%；2 倍时才到 82%、98%、100%。同一节还引 Box 1 指出决定重复数的三个因素是**技术噪声、效应量、生物学变异**，其中生物学变异无法靠改流程消除，只能靠重复数平均掉。

把这三条用到因子设计上，判断顺序是：先由文献或预实验给出「值得关注的最小效应量」与「纯误差的量级」，再用事前功效分析算出每个条件需要的重复数 $r$，最后核对 $2^K\times r$ 的运行成本是否可接受；不可接受时，退路是减少因子（部分因子筛选）或减少水平（两水平 + 中心点），而不是把 $r$ 压到 1。

## 五、映射到扰动实验：$n$ 是细胞还是供体

共享正文 §7.5 末尾把功效语言翻译回单细胞：细胞数动辄上万，$p$ 值被样本量推到极小，「显著」成为默认状态；此时**检验的 $n$ 是细胞数而不是供体数**，把 $n$ 从细胞数换回供体数，功效曲线会整体左移。这与 3.2.1（伪重复）、3.2.2（分层与混合效应）是同一条约束的另一面：因子设计里每个「组合 × 重复」单元，在扰动实验里应当是一个供体/一孔，而不是一个细胞。

因此本节的设计矩阵映射要再加一列：**重复单位**。组合扰动的 $2^2$ 设计若只有一块板、每孔上万个细胞，$r$ 实际是 1，交互项没有误差分母；剂量梯度的多水平因子同理，浓度点再多也只覆盖了一条曲线，不构成重复。

## 阅读顺序

1. 先读《全因子试验设计》§1–§4，建立设计矩阵、$2^K$、交互列与三种设计的分工。
2. 读 §5，把重复、中心点与区组接到误差估计上；再读本导读 §三，把运行次数换算成误差自由度。
3. 读共享正文《显著不等于效应大》§6.1–6.4 与 §7.5，补齐功效的四个输入与事前功效分析流程。
4. 读共享正文《单细胞扰动实验的重复怎么设》§3.3 与 Table 1，用具体数字校准「多大效应量需要多少重复」。
5. 最后读《组合扰动如何判定真交互》与《小分子药物为什么必须做剂量梯度》，把因子与水平落到扰动实验的具体臂上。
