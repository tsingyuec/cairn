# 3.2.3 观察研究中的混杂、选择偏差与关联解释 · 导读

本节的目标是能画出简单因果图，说清共同原因（fork）与选择机制（collider 上的条件化）各自怎样造出偏差，并且不把预测出来的相关读成干预效果。

本节自有正文是《扰动为什么能推出因果：因果之梯上的关联、干预与反事实》，它按 Judea Pearl 的骨架把因果图、三种基本结构、d-separation 与 do 算子走了一遍，最后把工具映射回单细胞扰动。

辛普森悖论的凸组合推导已作为共享素材存放在 1.2.2（条件概率、联合分布与边缘化）目录，按“共享博客只存一份”的约定本节不再复制，只在此给出导读。

## 目标覆盖

- **画出简单因果图**：自有正文 §2.1 用外生变量 $U$、内生变量 $V$、赋值函数 $F$ 定义结构化因果模型，并给出“$X$ 导致 $Y$”“$Y$ 由 $X$ 和 $Z$ 共同导致”“$X \to Z \to Y$”三种陈述的图与方程对应；§3 给出 chain / fork / collider 三种三节点结构的画法与条件独立法则。共享博客 §3.2 则把“性别 → 用药、性别 → 恢复、用药 → 恢复”画成一张三节点 fork 图。
- **共同原因产生的偏差**：自有正文 §3.2 说明 fork 上 condition 在共同原因上，两端才独立；§8 第（4）条把细胞类型、批次、测序深度对成 fork，指出不校正就会在 A 与 B 之间造出非因果通路。共享博客 §2.2–2.3 用凸组合 $A = p_1 q + p_3(1-q)$ 证明：只要处理组偏向基线更差的子群，整体比较就会在子群结论不变的情况下反转。
- **选择机制产生的偏差**：自有正文 §3.3 讲 collider 是唯一“condition 之后反而相关”的结构，并说明“按某个结果筛选样本会凭空造出相关性”；§4 的 d-separation 判定表逐行演示同一个图在不同条件集合下结论如何翻转；§8 第（5）条给出对应做法——按响应强度挑细胞等于在 collider 上条件化。共享博客 §5 第（3）条从扰动实验侧重复了同一个陷阱。
- **不把预测相关解释为干预效果**：自有正文 §5.1 并排对比 condition $P(Y \mid X)$ 与 do $P(Y \mid do(X))$，说明 do 在图上是删掉所有指向该变量的边；§6 给出调整公式、后门准则与逆概率加权（倾向得分），说明从观测数据算干预效应需要可观测的调整集；§8 第（1）（3）条明确“A 高时 B 也高”与“敲掉 A 后 B 变了”分属因果之梯的两层，且后者仍不等于“A 直接调控 B”。共享博客 §3.2 的结论同向：整体数据上“吃药的人恢复更差”不是药无效，而是混杂造成的非因果通路。

## 阅读顺序

1. 先读共享博客《辛普森悖论：忽略混杂变量，整体与分组会给出相反结论》§1–§3，用三个具体数据表建立“同一批数据整体与分组结论相反”的直觉，并看到反转的数学机制是凸组合。
2. 再读本节自有正文 §2–§4，把上一步的直觉升级成图：fork 解释共同原因，collider 解释选择偏差，d-separation 是统一判据。
3. 最后读自有正文 §5–§6 与 §8，把 condition 与 do 分开，并知道从观测数据估计干预效应需要什么调整集。

- 本节只到“后门/前门准则 + 调整公式 + 逆概率加权”的识别层面；随机分配如何解决混杂、依从性与外推限制留给 3.2.4。
- 重复测量与分层结构本身（伪重复、组内相关、随机效应）在 3.2.1 与 3.2.2，本节不重复。
- 自有正文 §7 的反事实（外展—干预—预测三步）超出本节学习目标，属因果之梯第三层，可作为延伸阅读，不要求掌握。
- 未覆盖：工具变量、断点回归、双重差分、敏感性分析（E-value 一类）、以及纵向数据中的时变混杂。现有素材没有对应讲解，需要时另行补素材。
