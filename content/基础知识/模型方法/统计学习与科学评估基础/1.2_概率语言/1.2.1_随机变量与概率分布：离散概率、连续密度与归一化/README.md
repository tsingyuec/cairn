# 1.2.1 随机变量与概率分布：离散概率、连续密度与归一化 · 导读

本节只做一件事：把“概率质量”和“概率密度”分开，并用一个离散例子和一个连续例子说明归一化与区间概率。期望、方差、协方差留给 1.2.4；条件化与边缘化留给 1.2.2。

## 学习目标覆盖

- **离散概率质量与归一化**：由《Top-P 采样》§二、§四给出。它把词表上的概率写成 $P(w\mid w_{<t})$，用“所有候选概率之和为 1”定义概率质量；截断后核内概率只剩 $p$ 左右，必须除以核内总和做重归一化，才能继续当概率使用。这正是“概率质量必须加和为 1”的离散例子。
- **连续密度与区间概率**：由《DDPM 大白话》§1.1–§1.2 给出。它从骰子点数之和的直方图过渡到钟形曲线，说明连续随机变量对应的是**概率密度曲线**；曲线下面积表示概率，总面积恒为 1；$\pm1\sigma$ 区间面积约 0.68、$\pm2\sigma$ 约 0.95。这里同时给出“密度不是概率、区间面积才是概率”和“密度归一化”的连续例子。
- **离散与连续的对照**：Top-P 的候选集是有限词表，概率可以直接相加；DDPM 的 $x$ 是连续取值，单点概率为 0，只能对区间积分。两篇材料并置，正好把“质量 vs 密度”的差别落在同一个归一化要求上。

## 边界提醒

- 《DDPM 大白话》其余章节讲前向加噪、重参数化、反向采样与贝叶斯推导，属于扩散模型主线，不是本节目标；本节只取 §1 的正态分布预备知识。
- 《Top-P 采样》后半讲的温度系数、Top-K 对比与工程实现，属于解码策略，不是本节目标；本节只取 §二、§四的概率质量与重归一化。
- 期望、方差、协方差与相关系数不在本节展开，见 1.2.4。
