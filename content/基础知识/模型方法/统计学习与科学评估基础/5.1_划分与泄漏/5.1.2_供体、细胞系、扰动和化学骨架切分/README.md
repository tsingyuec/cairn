# 5.1.2 供体、细胞系、扰动和化学骨架切分 · 导读

本节与 5.1.1 共用《生物信息学 AI 的数据泄漏陷阱：从「划分单位」到跨数据集验证》。按“共享博客只存一份”的约定，正文保留在 5.1.1 目录，本节不重复存放；本节自有正文是《同一个药换个细胞系还灵吗：药物细胞反应预测的跨细胞系泛化》与《虚拟细胞靠谱吗：先问考题是不是真的没见过》。

## 目标覆盖

- **供体轴**：共享博客 §四末尾说明按细胞随机切分会让同一供体、同一 10x 通道同时进入训练与测试，只有 leave-one-donor-out 才是真考题；§五把“按扰动 → 按细胞系/供体 → 按数据集”排成难度谱系；§八指出同一数据集内无论怎么切都共享供体与批次，只有跨数据集才能切断。
- **细胞系轴**：本节自有正文《同一个药换个细胞系还灵吗》§一用肿瘤三层异质性说明同一扰动在不同背景下的效应不同，§三用 CNV/miRNA 解释换背景为何失灵，§四给出 leave-cell-line-out 盲测，§九要求报告测试细胞系是否在训练集出现过。
- **扰动轴**：《虚拟细胞靠谱吗》§三区分按细胞、按扰动、按细胞背景三种切分，并把组合扰动按“单扰动是否学过”分层；《同一个药换个细胞系还灵吗》§四的新药盲测给出“换扰动比换背景更难”的对照。
- **化学骨架轴**：共享博客 §四提到按相似性聚簇划分（Butina 聚类与 scaffolds 整簇分配），§五用二维矩阵说明按行/按列切分对应“未见药物/未见靶标”，按相似性聚簇最难且要丢弃跨簇点。

## 阅读顺序

1. 先读共享博客 §四–§五，建立“划分单位就是难度旋钮”的统一视角。
2. 再读本节两篇自有正文：细胞系轴与扰动轴各自有独立的实验证据。
3. 需要时间切分与同源/结构切分时，回到 5.1.1 的同一篇 §四–§八。

## 边界与缺口

- 化学骨架轴只有“按骨架/相似性聚簇切分”的框架级说明，没有 Murcko 骨架定义、按骨架切分后化学空间如何分离、scaffold hopping 外推失败的具体数字。
- 供体轴只有定性论述，缺“按供体 vs 按细胞切分，同一模型分数差多少”的实测数字。
- 共享博客中的 0.85→0.38、CDR H3 中位 20% 等数字来自讲者幻灯片，引用时应注明“幻灯片报告值”。
