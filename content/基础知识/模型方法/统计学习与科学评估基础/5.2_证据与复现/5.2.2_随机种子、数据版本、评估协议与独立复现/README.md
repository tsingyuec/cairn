# 5.2.2 随机种子、数据版本、评估协议与独立复现 · 导读

本节把“独立复现”拆成两半：一半是**运行条件**（种子、版本、路径、日志、一条命令），另一半是**评估协议**（指标定义、数据切分、答案比对、基准污染与裁判效度）。前者保证别人能跑出同一串数字，后者保证这串数字真的在回答同一个问题。

## 学习目标覆盖

- **固定随机种子、数据版本与运行环境**：由《可复现与记录》§二给出六个会让结果悄悄变调的来源——随机种子、集合顺序、浮点加法顺序、软件包版本、抽样规则版本、系统语言设置；§四–§八 给出原始数据只读、参数集中、日志、校验和、git 快照与一条命令重跑的记录方式。
- **固定评估协议**：由《Lecture 12: Evaluation》§一给出“把抽象期望翻译成具体指标”的框架，并区分四种常见的“好”；§三.6 说明答案比对规则本身会改变分数；§三.7 讨论题目是否已被训练过（基准污染）；§四.4 给出“怎么判断一个指标本身好不好”的判据；§四.2 讨论人类裁判的偏差。这些合起来就是“评估协议需要固定哪些东西”的清单。
- **独立复现需要记录的最小信息**：《可复现与记录》§五 日志字段、§六 git 快照、§八 一条命令重跑，给出最小记录集；《Lecture 12》§一–§四 补充“协议”这一层：同一模型换指标、换比对规则、换裁判，结论可能不同，因此协议也必须写进记录。

## 边界提醒

- 《Lecture 12: Evaluation》是 LLM 评估讲座，§二–§七 的大量基准（MMLU、GPQA、SWE-bench、ARC-AGI 等）属于序列模型评估专题，不是本节目标；本节只取 §一、§三.6–§三.7、§四.2、§四.4 的协议与效度概念。
- 《可复现与记录》里的 GWAS 练习与流程管理工具是运行示例，不要求掌握具体工具；本节只取“记录什么、为什么这些字段足够”的推理链。
- 统计功效与样本量见 3.1.2；数据泄漏与切分见 5.1；本节不重复这些内容。
