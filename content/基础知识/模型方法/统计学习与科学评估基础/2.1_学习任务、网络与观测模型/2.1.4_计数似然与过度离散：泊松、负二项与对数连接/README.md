# 2.1.4 计数似然与过度离散：泊松、负二项与对数连接 · 导读

本节与 3.2.1 共用《细胞是观测，供体才是重复：Donor-level 差异分析的五个步骤与三个前提》。按“共享博客只存一份”的约定，正文保留在 3.2.1 目录，本节不重复存放；本节自有正文是《对数连接把计数均值放到加法尺度：泊松与负二项的 GLM 读法》与《过度离散从哪里来：泊松回归的均值—方差假设与负二项补救》。

## 目标覆盖

- **泊松与负二项的分布假设**：本节自有正文《对数连接》第一、三、四节给出 log 连接、$\log \mu = \eta$、均值恒正、泊松均值等于方差、负二项只放宽方差；《过度离散》第一节用 $E[y]=\mathrm{Var}[y]=\lambda$ 点明泊松的硬约束。
- **过度离散的来源与检查**：本节自有正文《过度离散》第三节给出离散参数检查，第四节把来源分成三类——设定错误、零过多、分布本身不够宽；第六节把似然选择落到下游模型。
- **对数连接与 GLM 读法**：本节自有正文《对数连接》第五节说明系数在 log 尺度上相加、回到均值尺度是乘性效应；第六节给出从似然到 GLM 的完整读法。
- **计数模型在真实分析中的用法**：共享博客 §三给出“聚合 → 过滤 → 归一化 → 建模 → 检验”的五步流水线，§3.1 说明为什么第一步必须是求和而不是取平均，§四说明负二项 GLM 与拟似然 F 检验，§九比较 DESeq2 / edgeR / limma-voom 的适用条件。本节只取这条“计数似然如何进入差异分析”的应用链，不重复 3.2.1 的伪重复论证。

## 阅读顺序

1. 先读本节《对数连接》与《过度离散》，建立泊松/负二项/对数连接的分布语言。
2. 再读共享博客 §三–§四，看这套似然如何落到 donor-level 差异分析的建模步骤。
3. 需要伪重复与实验单位的论证时，回到 3.2.1 的同一篇 §一–§二。
