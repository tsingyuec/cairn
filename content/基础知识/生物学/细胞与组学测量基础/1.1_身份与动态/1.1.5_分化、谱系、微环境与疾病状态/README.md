# 分化、谱系、微环境与疾病状态

本节把「分化谱系」与「微环境信号」接起来，再看疾病状态如何同时改变细胞的表达程序与群体组成。分化与谱系的基础机制由 B01 §4.3.4 的博客承担，微环境的信号链条由 B01 §4.1.2 的博客承担；本节新增的一篇博客承担「疾病状态如何改变表达与组成」这一层。

## 学习目标覆盖

- **连接分化谱系与微环境信号**
  - 分化的实质是基因选择性表达而非基因丢失，谱系是潜能逐级收窄（全能→多潜能→多能→单能，干细胞→祖细胞→终末细胞）：见 [细胞分化与干细胞：命运如何被决定，又如何被重编程](../../../生命科学基础主干/4.3_细胞增殖、生殖与命运调控/4.3.4_干细胞、自我更新与细胞分化/细胞分化与干细胞：命运如何被决定，又如何被重编程.md) 第一节 1.1–1.5 与第四节 4.1–4.5。
  - 谱系并非绝对不可逆：同文第二节 2.3 与第六节 6.1–6.6 讲重编程与诱导多能性，说明「稳定」是相对的。
  - 命运决定的两类来源：内部因素（细胞质不均、母源 mRNA 与决定子）见同文第三节 3.1；外部因素（胚胎诱导的几种信号模式、决定早于分化、细胞记忆）见同文第三节 3.2–3.3。
  - 微环境信号的形式与链条（旁分泌、内分泌、突触、接触依赖等；配体→受体→胞内级联→转录因子→靶基因）：见 [细胞通讯与微环境：配体受体、niche 与信号推断](../../../生命科学基础主干/4.1_细胞类型、基因表达与表观遗传/4.1.2_细胞类型、状态与微环境/细胞通讯与微环境：配体受体、niche与信号推断.md) 第一节 1.1–1.2。
  - niche 的定义与尺度：同文第五节 5.1、5.3。
  - 两者的直接连接：同文第三节 3.3 的 Kupffer 细胞 niche 对迁入单核细胞的「组织刻印」，以及第五节 5.2 的肝小叶梯度把同一细胞类型切成不同状态；反向连接见新增博客第一节 1.2——肿瘤微环境把 CD4⁺ T 细胞推向 Treg、把巨噬细胞推向 M2。
  - 通讯推断的边界：同文第四节 4.2，换工具或数据库后一致性很低，AUC 可接近 0.5，不能把配体—受体打分直接当成真实信号。
- **说明疾病状态如何改变表达与组成**
  - 三层框架「组成／状态程序／相互作用」：见 [正常组织与病变组织的细胞状态差在哪里：肿瘤微环境、癌前中间态与自身免疫重塑](正常组织与病变组织的细胞状态差在哪里：肿瘤微环境、癌前中间态与自身免疫重塑.md) 中心思想与第六节小结。
  - 组成改变：同文第二节 2.2、第三节 3.2、第五节 5.3。
  - 状态程序改变：同文第一节 1.2、第二节 2.2、第三节 3.5、第五节 5.1 与 5.3。
  - 表达改变先于形态改变：同文第五节 5.2 的甲状腺癌「癌前状态」案例。
  - 细胞间相互作用改变：同文第三节 3.4 的 CD47–SIRPα，以及第五节 5.3 的干扰素—成纤维细胞活化。
  - 治疗本身也是一种刺激：同文第四节，化疗有效与无效样本中 CCL18⁺ 巨噬细胞的变化方向相反。
  - 对照设计与读出边界：同文第二节 2.1、第三节 3.1、第五节 5.3，以及第一节 1.1、第三节 3.3–3.4。

## 阅读顺序

先读 B01 §4.3.4 的第一、二、四、六节，建立「分化＝选择性表达、谱系＝潜能收窄、谱系可被重编程」的主线。再读 B01 §4.1.2 的第一、三、五节，把微环境信号读成「配体→受体→转录程序」的链条，并理解 niche 是信号发生的局部尺度。最后读本节新增博客：先看第一节如何用肿瘤微环境把分化方向与微环境信号接起来，再按第二至五节看疾病状态在组成、状态程序与细胞相互作用三个层面留下的读数。

## 边界

本节不展开干细胞重编程的分子细节与多能性网络，那属于 B01 §4.3.4 的正文；不展开细胞通讯推断算法与空间邻域统计，那属于 [5.2.1](../../README.md#b04-5-2-1) 与空间组学相关小节。疾病状态只建立「组成／状态／相互作用」三类读数，具体疾病图谱与临床结论不在此处验收。
