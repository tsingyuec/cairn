# 细胞类型、细胞状态与细胞周期

本节把「类型」「状态」「周期相位」三个层次拆开，再回答一个测量问题：同一群细胞里混着不同状态时，组间比较读到的到底是什么。类型的定义与注释证据由 B01 §4.1.2 的博客承担；周期相位怎么读由 B01 §4.3.1 的博客承担；本节新增的一篇博客承担「同一类型内部混着多种状态」以及「细胞周期如何污染比较」这两件事。

## 学习目标覆盖

- **区分类型与状态（类型是坐标，状态是当前在做什么）**
  - 类型的定义方式：见 [细胞类型怎么定义、怎么鉴定：从 marker 基因到参考表达谱](../../../生命科学基础主干/4.1_细胞类型、基因表达与表观遗传/4.1.2_细胞类型、状态与微环境/细胞类型怎么定义、怎么鉴定：从marker基因到参考表达谱.md) 第一节（传统上按组织、形态、功能定义，更严格的表述要求发育起源与当前功能结合）与第九节（位置与微环境、疾病会让同一类型读出不同表达程序，即「名字只是坐标，状态才是细胞实际在做的事」）。
  - 同一类型内部的差异有多大：见 [细胞异质性从哪来：噪音、细胞周期与亚群](细胞异质性从哪来：噪音、细胞周期与亚群.md) 第一节——同一细胞系、同一培养条件，荧光强度仍逐个不同；约 500 个 Th2 细胞的 GATA3 转录本数从 1 条到近 350 条，连本该沉默的 TBX21 也有约 20% 的细胞随机表达。
  - 亚群常常是连续谱上切出来的段：同文 3.5，血清/LIF 培养的 mESC 里同时存在多能性基态、分化起始的中间态、已逃逸多能性三类细胞，并用一条分化时间序列验证第三类确实在自发分化。
- **区分状态与周期相位（相位是一种状态，且有自己的读数）**
  - 相位划分与物理读数：见 [细胞周期是细胞状态的时间轴：从周期蛋白波动与染色体形态，读出细胞处在哪个状态](../../../生命科学基础主干/4.3_细胞增殖、生殖与命运调控/4.3.1_细胞周期：生长、DNA%20复制与检查点/细胞周期是细胞状态的时间轴：从周期蛋白波动与染色体形态，读出细胞处在哪个状态.md) 第一节（G1/S/G2/M 与 DNA 含量 2C→4C）与第八节（持续增殖、G0、终末分化三种结局，以及 EdU 只能标记给药瞬间处于 S 期的细胞）。
  - 分子层读数：同文第四节，cyclin 随周期起落而 CDK 总量基本不变，只看几种周期蛋白的相对含量就能读出细胞主要停在周期的哪一段。
  - 相位是独立于类型的一条变异轴：见 [细胞异质性从哪来：噪音、细胞周期与亚群](细胞异质性从哪来：噪音、细胞周期与亚群.md) 3.3——血清组与 2i 组的总体噪音几乎一样，但 2i 组最「吵」的是有丝分裂/细胞周期基因，因为该组周期只有血清组的一半，细胞有足够时间停在某个相位把该相位的基因拉高；由此还能反过来用周期基因的噪音估计群体的相对增殖速度。
- **同一细胞群内混合状态对比较的影响**
  - 平均值丢掉分布：见 [细胞异质性从哪来：噪音、细胞周期与亚群](细胞异质性从哪来：噪音、细胞周期与亚群.md) 1.3，异质群体的 bulk 测序得到的是各亚群的加权平均，多样性信息在取平均那一刻就没了。
  - 先标定技术噪音，再谈生物学差异：同文 2.1，用 ERCC spike-in 拟合「表达量—细胞间变异」曲线作为噪音基线，只有变异显著超出这条曲线的基因才值得解释（该数据里约 900 个基因，功能富集在增殖上）。
  - 混合状态造成的假差异：同文 3.3 与 3.5——两种培养条件的差别表面上像「均一度」，实际一部分来自周期速度；比较「同一种细胞」时，两组的基态/分化态比例不同，读到的表达差里混着组成差。
  - 把相位当协变量剥离：同文 3.4，用潜变量模型把细胞周期回归掉之后，分化 marker 才变清楚。
  - 质控会误杀稀有状态：同文 3.2，2C 细胞因大量 reads 落在内源逆转录病毒序列上被当成坏细胞过滤，找回后才发现它们靠近的是囊胚阶段。

## 阅读顺序

先用 B01 §4.1.2 博客的第一节与第九节，把「类型」定义在组织、功能、发育起源与当前状态上，明确标签只是坐标。再用 B01 §4.3.1 博客的第一、四、八节，把周期相位读成一种有物理读数（2C/4C）、分子读数（cyclin 波）和行为读数（增殖/G0/终末分化）的状态。最后读本节新增博客：第一节看同一类型内部的差异有多大，第二节看怎么把技术噪音从生物学差异里分出来，第三节 3.3–3.5 看周期与亚群如何在同一群细胞里混起来、以及剥离周期后比较结果怎么变。第四节的 T 细胞轨迹与微环境只作背景浏览。

## 边界

本节不展开细胞周期的分子机器（MPF、Wee1/Cdc25、APC/C、检查点细节），那属于 B01 §4.3.1 的正文；也不展开注释工具、参考数据集与相似度算法，那属于 [3.2.4](../../README.md#b04-3-2-4) 与 [3.2.5](../../README.md#b04-3-2-5)。新增博客第四节的 T 细胞并行轨迹、拟时序与微环境信号分别属于 [5.2.1](../../README.md#b04-5-2-1) 与 [1.1.5](../../README.md#b04-1-1-5) 的范围，本节只把它读作「状态还有外部来源」的背景，不在此处验收轨迹推断。周期相位如何进入差异表达与组成比较，留到第 4 章处理。
