# 染色质可及性测量：ATAC-seq、开放区域与调控线索

本节回答一个具体的测量问题：染色质可及性本身不是一种分子，它怎么变成测序仪能读的片段、又怎么变成一张「峰 × 细胞」的计数矩阵；以及拿到这张矩阵之后，哪些话可以说、哪些话不能说。

两篇正文分工明确：[单细胞 ATAC-seq 原理](单细胞ATAC-seq原理：Tn5标记开放染色质与10x条码化.md)讲**酶与文库**——Tn5 为什么只切开放区、片段长度谱为什么是质控指纹、scATAC 为什么没有 UMI；[单细胞 ATAC-seq 的数据形态](单细胞ATAC-seq的数据形态：从bulk平均轨道到细胞乘峰矩阵.md)讲**从轨道到矩阵**——bulk 平均丢掉什么、细胞 × 峰矩阵长什么样、pseudo-bulk 轨道怎么把矩阵读回基因组坐标。两篇合起来构成「转座酶切入 → 片段 → 峰计数 → 判读」这一条链。

## 学习目标覆盖

学习目标：解释转座酶切入和可及区域计数，区分开放性、转录因子占据和真实调控。下面拆成三个检查点逐条给出覆盖位置。

- **转座酶切入：Tn5 为什么只切开放染色质，切完得到什么**
  - 前提是核小体挡路：见 [单细胞 ATAC-seq 原理](单细胞ATAC-seq原理：Tn5标记开放染色质与10x条码化.md) 1.1——DNA 缠在核小体上，被包住的区域转录因子进不去，因此「够不够得着」本身是调控的一环；同文 SCQA 的「冲突」段把这件事与表达矩阵的读出对照：基因没表达，可能是缺转录因子，也可能是那段染色质被封住，两者在表达矩阵里长得一样。
  - 三种酶切出三种图：同文 1.2 的对照表——MNase-seq 切核小体之间的连接 DNA（读出核小体占据）、DNase-seq 只切开放处（读出超敏位点）、Tn5 两边都切（读出全部可及区），差别只在「切哪里」这一列。
  - 一步完成三件事：同文 1.3 的四格过程——Tn5 携带接头只落在核小体之间的空隙，把「识别开放区、剪切、接接头」合成一步，这也是起始量能低到约 2000 个细胞的原因（同文第二节第三条）。
  - 片段长度谱是数据的指纹：同文 1.4——小于 100 bp、约 200 bp、约 400 bp 三个周期峰分别对应无核小体、单核小体、双核小体跨度；文库跑一次 TapeStation 或直接统计 read 对长度都能看到，没有周期性说明转座反应没做好。另一篇 [数据形态](单细胞ATAC-seq的数据形态：从bulk平均轨道到细胞乘峰矩阵.md) 1.1 的五步流程与「闭合 vs 开放」对比图给出同一机制的另一视角。
  - 单细胞化只加一层条码：原理篇第三节——转座在进液滴**之前**于整管核悬液里批量完成，液滴内只做「一个核 + 一颗珠 + 线性扩增」，破油后再补 P7 与样本 index；化学过程没变，变的是每个片段多了一段属于某个细胞的条码。

- **可及区域计数：从片段到「峰 × 细胞」矩阵**
  - 为什么没有 UMI、计数是什么：原理篇第四节——二倍体细胞每条染色体只有两份拷贝，同一坐标出现两份以上片段逻辑上必然是 PCR 重复，按坐标去重即可，不需要分子标签。这条推理直接决定 scATAC 的计数是「这个细胞的这个位点被测到几个片段」，而不是「几个原始分子」，也因此比 scRNA 更稀疏、更接近二值。
  - 三种数据视图：数据形态篇第四节——左上是一条 bigWig 平均轨道（bulk 的输出形态），左下是 tSNE 散点（每个点一个核，12 个簇），右边是 12 个簇各自的 peak profile。同一张幻灯片说明单细胞化的分水岭：bulk 给你一条曲线，单细胞给你「一群细胞各一条曲线」。
  - 峰与矩阵的具体规模：数据形态篇 5.2——人造血图谱在 63,882 个核里识别 31 个簇，并汇总出「细胞类型 × 16,773 个差异可及位点」的热图；这就是「峰 × 细胞」矩阵按行（峰）取子集、按细胞群聚合之后的形态。
  - pseudo-bulk 把矩阵读回坐标：数据形态篇第四节与 5.3——把同一群细胞的所有片段合并成一条轨道，才能和 bulk 的 bigWig 直接对照；BCC 案例里 CD47、TGFB1、PD-L1 三个位点的差异就是这样在细胞类型与病人之间看出来的。
  - 稀疏性的下游后果：原理篇第四节结尾指出 scATAC 没有「分子计数」这一层，只有「有没有被测到」；稀疏矩阵本身的数据对象形态见 [§2.2.1](../../README.md#b04-2-2-1) 与 [§2.2.2](../../README.md#b04-2-2-2)。

- **开放性、转录因子占据与真实调控：三个读数的边界**
  - 开放性说的是「够得着」，不是「正在转录」：原理篇 SCQA 的「冲突」段与 1.1——可及性回答基因「能不能」被转录，scRNA-seq 回答「正在」转录什么；B01 §4.1.1 的博客把同一层意思讲得更直白：核小体松开只是把门打开，「只是有可能开始表达」，还没有决定要不要进去，见 [基因表达调控的三个层次](../../../生命科学基础主干/4.1_细胞类型、基因表达与表观遗传/4.1.1_基因表达调控与表观遗传/基因表达调控的三个层次——染色质、转录起始与转录后.md) 一与二.2.1。
  - 开放 ≠ 激活：原理篇第二节第一条——讲者明确问「这些开放区是不是都是激活位点」，答案是**不一定**；阻遏蛋白同样要结合到染色质上才能起作用，一结合就把那段 DNA 保护起来，Tn5 也就切不进去。所以「开放」只说明「有蛋白在这里落脚」，落脚的是激活因子还是抑制因子，要靠 motif 分析等手段再判断。
  - 占据会让可及性信号变弱，因此「没有峰」不等于「没有蛋白」：同上一段——抑制性复合物结合后保护 DNA、Tn5 切不进去，说明占据与开放不是同一个读数，可及性下降既可能是染色质关闭，也可能是被某个蛋白占住了；单凭 ATAC 无法区分这两者。
  - motif 命中只是候选，不是占据证据：数据形态篇 1.2 第三条——对开放区做 motif 分析可以找出**可能**驱动细胞命运、疾病或响应的转录因子；5.2 的造血轨迹案例也是用「开放谱 + motif」推断每一步涉及哪些转录因子。这类结论是「序列上说得通」的候选，不等于该蛋白真的结合在该位点。motif 命中、真实结合与功能调控三者的区分属 [B02 §3.1.3](../../../基因组与基因调控基础/README.md#b02-3-1-3)，可及性与转录因子结合的一般关系属 [B02 §3.1.4](../../../基因组与基因调控基础/README.md#b02-3-1-4)（当前 WAITING）。
  - 开放 ≠ 真实调控：原理篇第六节——表观遗传信息必须放在基因表达的语境里解释，只看「哪里开放」而不看「哪些基因在表达」，很难判断这个开放位点到底在调控什么；同一细胞核的 Multiome 之所以重要，正是因为它把表达与可及性绑在同一个条码上，可以直接问「这个基因表达高低」与「它启动子区可及性」是否一致。数据形态篇 5.2 的轨迹 + motif 结论也属于「与表达/状态一致」的旁证，不是因果证据。
  - 本节的判读边界（导读整理）：ATAC 读数里既没有蛋白身份，也没有转录后果。要判断「这个位点调控了哪个基因」，需要额外的表达测量（同细胞 Multiome 或配对样本）或对位点的扰动实验；扰动本身的设计与识别假设属 [§5.1.2](../../README.md#b04-5-1-2) 与 [§5.1.3](../../README.md#b04-5-1-3)，蛋白—DNA 结合的直接测量属 [§1.2.5](../../README.md#b04-1-2-5)。

## 阅读顺序

先读 [单细胞 ATAC-seq 原理](单细胞ATAC-seq原理：Tn5标记开放染色质与10x条码化.md)：1.1–1.2 建立「核小体挡路 → 三种酶切三种图」的对照，1.3 看 Tn5 一步完成识别、剪切、接接头，1.4 把片段长度谱当作质控指纹读；第二节顺手给出本节最重要的一条判读警告（开放 ≠ 激活）；第三节到第四节讲单细胞化与文库结构，其中「为什么没有 UMI」的推理决定了后面计数的含义。再读 [数据形态](单细胞ATAC-seq的数据形态：从bulk平均轨道到细胞乘峰矩阵.md)：1.1 用五步流程复述同一套化学，2.1 用 CD33 位点说明 bulk 平均如何掩盖稀有亚群，第四节把 bigWig、tSNE、peak profile 三种视图并排看，5.2 与 5.3 给出矩阵在真实图谱里的规模与用法。最后回到原理篇第六节，把「可及性必须与表达一起读」这条边界收口。

## 边界

本节只处理可及性这一种表观组读出：Tn5 的切入化学、片段到峰计数的形态、以及「开放—占据—调控」三层的证据边界。蛋白—DNA 结合与组蛋白修饰的直接测量（ChIP-seq、CUT&Tag 的免疫富集与靶向转座）属 [§1.2.5](../../README.md#b04-1-2-5)；同细胞多模态配对与计算匹配属 [§1.2.6](../../README.md#b04-1-2-6)；建库化学、条形码与 UMI 的分子机制属 [§2.1.2](../../README.md#b04-2-1-2) 与 [§2.1.3](../../README.md#b04-2-1-3)；读段量化与峰 calling 的具体算法属 [§2.1.6](../../README.md#b04-2-1-6)；归一化、降维与聚类属 §3.1 与 §3.2；motif 与转录因子识别的分子机制属 B02 §3.1.3–§3.1.4。两篇正文里提到的平台路线（板式、液滴、split-pool）只作为「单细胞化怎么做」的背景，平台横向比较不在本节验收。
