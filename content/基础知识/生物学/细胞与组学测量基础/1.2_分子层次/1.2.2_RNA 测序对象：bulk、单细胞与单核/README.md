# RNA 测序对象：bulk、单细胞与单核

本节比较三种测量对象：一管组织的混合样本（bulk）、完整单细胞、单细胞核。三者的差别不在测序仪，而在**测序之前把什么东西装进了管子**——这决定了读数是平均值还是单个细胞、读到的 RNA 来自细胞的哪一部分、以及什么样的样本才做得了。两篇正文分别承担「bulk 与单细胞的混合效应」和「完整细胞与细胞核的捕获对象与样本条件」。

## 学习目标覆盖

- **混合效应：bulk 的平均值丢掉什么**
  - 平均的直观含义：见 [Bulk 与单细胞 RNA-seq 的分辨率差异与适用场景](Bulk与单细胞RNA-seq的分辨率差异与适用场景.md) 第一节——把多种水果打成一杯果昔，尝到的是所有水果混合后的味道；bulk 的定量值是「在所有细胞上平均过的」。
  - 稀释与抵消：同文 1.1，只发生在肿瘤浸润免疫细胞里的表达变化，在整块组织的平均里会被稀释掉，因此「病人与健康人整体有什么差异」用 bulk 就够，而「哪一类细胞变了」必须下沉到细胞层面。
  - 两种数据的目标分工：同文 3.1（bulk 用于识别样本之间/条件之间的差异，单细胞用于识别细胞类型之间/状态之间的差异）与第六节（bulk 走差异表达与共表达网络，单细胞走聚类注释与每簇标志基因）。
  - 平均带来的代价：同文第二节的五维对照表——单细胞更贵、更费人工、统计更复杂，换来的是异质性与亚群表达不被掩盖。
- **捕获对象：一次测量装进去的是什么**
  - bulk 的捕获单位：同文 3.2，从样本里所有细胞一起提取 RNA、反转录、扩增，得到「基因 × 样本」的计数矩阵。
  - 单细胞的捕获单位：同文 3.2 与第五节，每个细胞单独提取并打上细胞 barcode 与 UMI，得到「基因 × 细胞」的矩阵，且每列还要先判定「是不是一个真细胞」。
  - 捕获的分子范围：同文 3.5 指出 bulk 能检测可变剪接，而单细胞常用的 3′ 端计数只测转录本的一端、拿不到完整剪接信息——同一台测序仪，捕获的分子范围已经不同。
  - 完整细胞捕获什么：见 [单细胞与单核 RNA 测序：捕获对象、样本条件与检出差异](单细胞与单核RNA测序：捕获对象、样本条件与检出差异.md) 1.1——scRNA-seq 研究的是「细胞核加细胞质中的 RNA」，反映细胞整体的转录状态。
  - 细胞核捕获什么：同文 1.2——snRNA-seq 只取细胞核，研究的是「细胞核中的 RNA」；第二节对照表「转录本代表性」一行把两者并列：一边是核内 RNA + 胞质 RNA，一边主要是核内 RNA。
  - 捕获内容不同带来的数据差异：同文第二节「数据质量」一行——完整细胞的基因检出数通常更高、背景噪声较低；细胞核检出数略低，且核分离可能引入碎片污染、核内 RNA 的剪接状态可能影响注释。
- **样本条件：什么样本走哪条路**
  - 样本层面的取舍（bulk 与单细胞之间）：[Bulk 与单细胞 RNA-seq 的分辨率差异与适用场景](Bulk与单细胞RNA-seq的分辨率差异与适用场景.md) 第二节（价格、人力、统计复杂度）与 3.3（质控对象是「一个文库」还是「成千上万个细胞」）。
  - 完整细胞的前置条件：见 [单细胞与单核 RNA 测序：捕获对象、样本条件与检出差异](单细胞与单核RNA测序：捕获对象、样本条件与检出差异.md) 第三节——新鲜组织、易于解离、关注细胞功能状态、需要较高基因检出数，四条同时成立时优先选 scRNA-seq。
  - 细胞核的适用条件：同文第四节——仅有冻存样本、脑/心脏/肾脏等致密组织、想保留神经元与心肌细胞等脆弱细胞类型、想避免解离诱导的转录应激。
  - 代价与时效：同文第二节「技术挑战」与「成本与时效」两行——完整细胞怕活性不足与解离应激、样本必须新鲜处理；细胞核要过滤线粒体 DNA 混入、核分离步骤可能更耗时，但冻存样本可直接实验。
  - 拿不准时怎么办：同文第五节——先做预实验比较数据质量、参考同类组织的已有文献、必要时混合使用（脑组织用 snRNA-seq、血液用 scRNA-seq）。

## 阅读顺序

先读 [Bulk 与单细胞 RNA-seq 的分辨率差异与适用场景](Bulk与单细胞RNA-seq的分辨率差异与适用场景.md)：第一节建立「平均」的直观含义，1.1 看平均如何稀释只发生在少数细胞里的信号，3.1 与 3.2 把两种数据的测量单位与捕获对象对齐，3.5 看捕获范围如何限制能做的分析，最后用第二节与第六节收在「样本/条件比较还是细胞类型比较」这条分界上。再读 [单细胞与单核 RNA 测序：捕获对象、样本条件与检出差异](单细胞与单核RNA测序：捕获对象、样本条件与检出差异.md)：1.1–1.2 看两条路线的前处理与捕获内容，第二节的对照表把七个维度一次看完，第三、四节给出选型判据，第五节是拿不准时的做法。
