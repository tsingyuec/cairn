# 中心法则、逆转录与 RNA 复制

本节的目标是辨认四条信息流，并把「信息怎么传」与「表型由谁决定」分开。前者由 2.1.2 已整理的博客承担，后者由本节新增的一篇博客承担——中心法则描述的是信息流向，不是性状的因果链。

## 学习目标覆盖

- **DNA → DNA（复制）**：见 [DNA 复制、转录与翻译：一张中心法则图看懂遗传信息流](../../2.1_DNA%20与遗传信息/2.1.2_DNA%20复制概览：半保留复制与遗传连续性/DNA复制、转录与翻译：一张中心法则图看懂遗传信息流.md) 第一节，半保留复制、解旋酶与 DNA 聚合酶、5′→3′ 方向与连接酶补缺口。
- **DNA → RNA（转录）**：同文第二节，RNA 聚合酶沿模板链合成 mRNA。
- **RNA → 蛋白质（翻译）**：同文第三节，密码子、tRNA 反密码子与核糖体移动方向；更细的起始、延伸、终止见 2.2.5。
- **RNA → DNA（逆转录）**：同文第 4.2–4.3 节，以 HIV 为例说明逆转录酶把 RNA 写成 DNA、整合进宿主基因组后潜伏。
- **RNA → RNA（RNA 复制）**：同文第 4.2 节，以烟草花叶病毒为例说明 RNA 病毒的自我复制。
- **区分信息传递与表型决定论**：见 [信息传递不等于表型决定：中心法则的边界、选择性表达与环境](信息传递不等于表型决定：中心法则的边界、选择性表达与环境.md)。该文把中心法则读成「五条箭头的流向图」而非性状的因果链（第一节，含对「逆转录推翻了中心法则」的辨析）；用「酶→代谢→性状」与「蛋白质结构→性状」两条路径说明从信息到表型之间还有可调控的环节（第二节）；用选择性表达（第三节）与表观遗传（第四节）说明同一套基因组可以读出不同表型；最后以一张「中心法则管不管」的分层表收束，把「决定」换成「约束」（第五节）。

## 阅读顺序

先读 2.1.2 博客的第一至三节，把复制、转录、翻译三条实线走通；再读第四节，把两条虚线（逆转录、RNA 复制）加到同一张图上。然后读本节新增的博客，重点看第一节（流向图而不是因果链）、第三节与第四节（同一基因型的不同表型）、第五节（分层表与三个常见误读）。最后回到本节，用「模板 → 产物」的句式复述四条流向，并各举一个例子。

## 边界

本节不展开逆转录病毒的整合机制、RNA 依赖的 RNA 聚合酶结构，也不讨论表观遗传与环境如何具体改变表型；这些分别在病毒学、酶学和 [4.1.1 基因表达调控与表观遗传](../../4.1_细胞类型、基因表达与表观遗传/4.1.1_基因表达调控与表观遗传/基因表达调控的三个层次——染色质、转录起始与转录后.md) 中处理。新增博客只把表观遗传当作「序列不变、表达可变」的证据，机制细节以 4.1.1 为准。2.1.2 博客中的单细胞语境段落可跳过。
