# 1.1.4 染色体、线粒体与质粒

本节回答一个问题：**一个细胞里的 DNA 不止一套，它们的遗传规则也不止一套**。核基因组在染色体上、按孟德尔规则父母各半；线粒体与叶绿体基因组在细胞质里、主要走母系；质粒独立于染色体、能自己复制也能水平转移。三者的差别不在「有没有 DNA」，而在**拷贝数、包装方式、遗传路径和分离精确度**。

本目录没有独立撰写全部正文，而是把已有正文按学习顺序编成一个导读：核基因组与质粒部分复用既有正文，细胞器基因组部分由两篇新整理的视频博客承担。

### 目标二：说明拷贝数与母系遗传的后果

| 后果 | 覆盖材料 | 具体覆盖了什么 |
| --- | --- | --- |
| 拷贝数的量级 | [线粒体基因组：几千个拷贝、母系遗传与异质性](线粒体基因组：几千个拷贝、母系遗传与异质性.md) 的「一、先看结构」 | 每个体细胞数百个线粒体 × 每个 2–10 拷贝 = 每细胞数千个 mtDNA；约占细胞 DNA 总量 1%；人类 mtDNA 为 16 569 bp 双链闭环，分重链/轻链。 |
| 多拷贝带来的第一个后果：遗传瓶颈 | 同上，「3.1 遗传瓶颈」 | 卵母细胞约 10 万个线粒体，成熟时锐减到不足 100 个，再经早期胚胎分裂回到每个细胞 1 万个以上；瓶颈放大抽样波动，使同一母亲的不同子女突变负荷不同。 |
| 第二个后果：阈值效应 | 同上，「3.2 阈值效应」 | 突变比例需达到组织特异的临界值才出现功能异常；肝脏 80% 突变可无症状，同样比例在骨骼肌或脑组织即出现病理症状；最先受损的是脑，其后为骨骼肌、心脏、胰腺、肾脏、肝脏。 |
| 第三个后果：同质性与异质性 | 同上，「3.3 同质性与异质性」 | 正常组织 mtDNA 一致为同质性；突变后同一细胞可共存野生型与突变型为异质性；同质性个体症状较重，异质性个体轻重取决于突变比例。 |
| 第四个后果：随机分离与组织差异 | 同上，「3.4 随机分离」 | 细胞分裂时 mtDNA 随机分配，组织间突变比例不同（抽血测的比例未必代表脑或肌肉）；但母亲突变比例越高，后代携带概率越大。 |
| 母系遗传的后果：家系判读 | 同上，「2.4 母系遗传」；[细胞质遗传](细胞质遗传：叶绿体与线粒体为何只走母系.md) 的「六、怎么一眼认出细胞质遗传」 | 家系中相同症状若都由发病女性连续传递，应考虑 mtDNA 异常；儿子的 mtDNA 不再下传，父系传递不能作为 mtDNA 遗传证据。 |
| 母系遗传的后果：变异解读 | 同上，「2.2 突变率高」「3.5 累加效应」 | 突变率高但有害突变可被选择性自噬清除，因此「变异常见」不等于「必然致病」；多个 mtDNA 突变对表型有累加效应，基因型—表型关系是「负荷」而非单变异对应单病。 |

### 未覆盖与待核对项

- **质粒拷贝数**：既有质粒正文讲的是独立复制与水平转移，没有展开拷贝数调控（拷贝数控制属于克隆操作层面，按本节边界不展开）。若后续需要，可另找材料补。
- **叶绿体基因组的分子结构**：两篇材料只说明叶绿体 DNA 存在且以母系遗传为主，未讲其大小、反向重复序列等结构细节。
- **父系渗入的具体数值**：新博客引用的「万分之二」来自课程视频的表述，引用前应回到原始研究核对，不宜当作常数。

## 边界

**本节讲什么**：三类 DNA 实体的基因组组织（环状/线性、单/多拷贝、包装方式）、遗传方式（孟德尔分离、母系遗传、水平转移）、以及拷贝数与母系遗传造成的后果（遗传瓶颈、阈值效应、异质性、组织差异、家系判读）。

**本节不讲什么**：

- **复制酶学**：质粒滚环复制只在「为什么它能独立复制」这一层引用，RepA、SSB、连接酶的分工细节属于复制机制，见既有质粒正文，本节不重述。
- **线粒体呼吸链与能量学**：13 个亚基如何组装、质子梯度如何驱动 ATP 合成属于能量代谢脉络；本节只用到「组织对氧化磷酸化依赖程度不同 → 阈值不同」这一层结论。
- **质粒克隆操作**：载体构建、转化、筛选等实验流程不在本节范围。
- **变异致病性判读**：mtDNA 变异的临床解释见 B02 §4.2.6，数据资源见 D01。
