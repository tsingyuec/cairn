# 科研文档与图像信息提取

编号：P11 · 类型：模型专题 · 目录规模：32 个小节（三级叶子节点，少于 100）。

**知识主线**：文档或图像 → 文字与布局 → 目标定位 → 可追溯的科研证据。

**范围与边界**：辅助专题：Unlimited-OCR；LocateAnything 仅作为来源模型仓库已有的定位工具背景，不暗示它是生物模型或当前已注册服务。

**前置知识**：所需的通用知识已纳入下方章节的复用小节，与本专题扩展交错排列；无需先通读任何上游整门课。

**组织与素材策略**：以模型机制、模型特有的工作流或输出判读为单元。先引用共享基础；同一模型报告可能覆盖多个问题，先登记覆盖范围再分配素材。

**本脉络的深度边界**：这是科研辅助方向，不要求补成完整计算机视觉课程。

> 小节按可独立理解和验收的机制、推理或判读任务划界。知识完整性优先；1–3 篇只是素材预算，同一长视频可跨小节引用，不能为减少重复采集而合并独立机制。

> 自有任务进度：`[WAITING]` 待处理 · `[PROCESSING]` 已认领 · `[DONE]` 已验收 · `[ABORT]` 终止。处理规则见项目 skill 的 `processing.md`。

> 内容构成：20 个自有写作小节，12 个通用复用小节。`[REUSE]` 是课程内容类型，不是进度状态；计入本脉络小节规模，但不另建正文或认领任务。

## 1 视觉表示与科研文档对象

### 1.1 张量、视觉词元与页面要素

- 1.1.1 向量、矩阵、张量与维度 <a id="p11-1-1-1"></a> [REUSE](../../../基础知识/模型方法/统计学习与科学评估基础/README.md#m01-1-1-1)
  - 学习目标：说明向量、矩阵与张量的维度约定和广播规则；判断模型输入输出的形状；把线性代数记号与后续网络实现对应起来。
- 1.1.2 嵌入向量、词表与特殊标记 <a id="p11-1-1-2"></a> [REUSE](../../../基础知识/模型方法/序列建模与基础模型/README.md#m02-1-1-4)
  - 学习目标：说明嵌入向量、词表与特殊标记的作用；判断 token 化对序列长度和语义的影响；把输入表示与模型输出、下游任务对应起来。
- 1.1.3 科研文档要素：文本、版面、表格、公式与图像 <a id="p11-1-1-3"></a> [WAITING]
  - 学习目标：以一页论文区分识别、解析和推理对象。
- 1.1.4 卷积网络、局部感受野与模式提取 <a id="p11-1-1-4"></a> [REUSE](../../../基础知识/模型方法/序列建模与基础模型/README.md#m02-2-1-2)
  - 学习目标：说明卷积核、局部感受野与权值共享；判断卷积层如何提取文档图像/文本模式；把卷积特征与 Transformer 的全局注意力区分开。
- 1.1.5 文档视觉编码：图像分辨率、patch 与视觉 token <a id="p11-1-1-5"></a> [WAITING]
  - 学习目标：说明页面信息进入视觉特征的过程及分辨率/压缩取舍，不扩大为完整视觉主干课程。

### 1.2 条件注意力与多模态解码

- 1.2.1 交叉注意力：条件注入、查询来源与序列对齐 <a id="p11-1-2-1"></a> [REUSE](../../../基础知识/模型方法/序列建模与基础模型/README.md#m02-2-2-7)

- 1.2.3 约束解码、条件提示与候选重排序 <a id="p11-1-2-3"></a> [REUSE](../../../基础知识/模型方法/序列建模与基础模型/README.md#m02-4-1-2)

## 2 上下文建模与长文档解析

<a id="p11-2-1"></a>

### 2.1 窗口、因果可见性与跨页机制

- 2.1.1 截断、填充、掩码与上下文窗口 <a id="p11-2-1-1"></a> [REUSE](../../../基础知识/模型方法/序列建模与基础模型/README.md#m02-1-2-3)
  - 学习目标：说明截断、填充、掩码与上下文窗口的用途；判断长文档处理中的信息损失；把输入构造与模型位置编码、注意力范围对应起来。
- 2.1.2 因果注意力：掩码、训练并行与逐步生成 <a id="p11-2-1-2"></a> [REUSE](../../../基础知识/模型方法/序列建模与基础模型/README.md#m02-2-2-8)
  - 学习目标：围绕信息可见性读通一次训练和生成。
- 2.1.3 文档版面分析：页面预处理、区域识别与内容分块 <a id="p11-2-1-3"></a> [WAITING]
  - 学习目标：以一页科研文档定位正文、标题和图表区域，解释切块分辨率与布局损失，不同时承担跨页记忆机制。
- 2.1.4 文档阅读顺序：多栏排列、层级关系与结构恢复 <a id="p11-2-1-4"></a> [WAITING]
  - 学习目标：从版面区域重建线性/层级内容，检查跨栏与图注归属，区分检测正确与逻辑顺序正确。
- 2.1.5 注意力复杂度与长序列计算 <a id="p11-2-1-5"></a> [REUSE](../../../基础知识/模型方法/序列建模与基础模型/README.md#m02-5-1-1)
  - 学习目标：说明注意力复杂度与序列长度的关系；判断长文档上下文窗口的计算限制；把复杂度与 2.1.6 的高效注意力、5.1 的长上下文处理联系起来。
- 2.1.6 高效注意力：稀疏、线性与分块计算 <a id="p11-2-1-6"></a> [REUSE](../../../基础知识/模型方法/序列建模与基础模型/README.md#m02-5-1-2)
  - 学习目标：说明稀疏、线性与分块注意力的机制；判断不同方案对长文档跨页建模的代价；把高效注意力与 2.1.5 的复杂度、5.1 的检索增强区分开。
- 2.1.7 Unlimited-OCR 长文档机制：跨页状态与参考注意力 <a id="p11-2-1-7"></a> [WAITING]
  - 学习目标：按版本核对长文档状态维护与 Unlimited-OCR 2 的 SR-SWA，解释有限窗口内的参考信息；不能用通用 OCR 流程替代模型特有机制。
- 2.1.8 OCR 方法谱系：检测—识别两阶段、CTC 与端到端多模态 <a id="p11-2-1-8"></a> [WAITING]
  - 学习目标：对照两阶段、CTC 序列识别与端到端多模态路线，说明适用条件与错误模式。
