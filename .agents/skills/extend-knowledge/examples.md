# 目录扩充的判断实例

这些是归类示例，不表示以下模型或数据已接入，也不要求照抄示例章节。

## 增加同家族的结构预测模型

**情况**：一个新模型仍然针对蛋白—配体复合物，用相近的全原子生成路线，但增加了不同的条件信息。

**处理**：先读现有“生物分子结构预测”脉络。如果输入对象、评价与主线基本相同，在同一篇补该模型的差异小节；扩散、等变性和结构置信度仍引用公共基础。不因为模型有新名称就再建一份“中心法则—Transformer—扩散”课程。

**不同情况**：如果它实际预测分子响应而非结构，不能因名字像 AlphaFold 就放入结构预测；应按真实任务重新判断。

## 增加一个 Perturb-seq 原始研究

**情况**：一个研究发布了基因扰动的单细胞矩阵，也被 scPerturb 收录；biodata 为其新建了查询页面。

**处理**：区分原始研究、官方矩阵、scPerturb 整理版本和本地页面。优先在“单细胞图谱与扰动原始资源”中增加研究设计、干预与对照、测量和可比性内容；说明它与 scPerturb 的来源关系，不把查询页面新建成一个数据库脉络。若已能由现有小节完整表达，只补原始资料与案例入口。

## 增加真正独立的空间组学方向

**情况**：现有单细胞目录只交代空间测量概念，新资源引入空间坐标、测量分辨率、细胞分割和邻域关系。

**处理**：若核心对象和误差机制已无法自然放入现有主线，可新建空间组学数据脉络。表达计数、批次效应、样本重复仍引用公共基础；空间采样、分割、配准、邻域和组织结构是新增内容。不要先把整个单细胞基础复制过去。

**边界**：如果多个模型和资源都要讲“空间邻域与分辨率”，把独立公共概念提炼进生物学或模型基础，资源篇保留测量产品和证据差异。

## 新增本体检索接口

**情况**：一个服务开始查询 CL、Uberon 或 MONDO，平台新增了一个统一检索页面。

**处理**：现有原始本体身份不变；新增服务入口不等于新增生物学资源。只有出现新的本体科学对象或独有注释产品时，才扩充对应知识。服务 API 和部署方式不进入知识目录。

## 内部模型或实验没有公开站点

如实记录内部一手来源、授权边界、任务和未确认事项。公共抗体序列库或结构库可作为参照，但不能据此推断内部数据来自这些库。不要生成看似真实的官方 URL，也不要把使用接口说明当作原始训练证据。

## 脉络接近规模上限

**情况**：现有 94 个小节，新增内容需要 8 个独立小节。

**处理**：102 个小节不符合少于 100 的约束。先识别可独立学习的科学问题，例如“抗体结构与生成”和“抗体工程与可开发性”，再拆分、保留共享基础引用，并更新全部入链、统计及学习路线。不得把 8 个不同问题硬压成 1 个标题来绕过上限。

## 交付摘要示例

“新增某原始资源，补入 D 系列现有脉络，原因是科学对象与评价主线相同；复用计数矩阵和实验单位小节，新增测量条件与来源局限。已同步分类、总目录与项目统计；静态链接和编号检查通过。官方数据许可尚需核对，未据软件许可证推断。”
