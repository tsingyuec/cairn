# 整合式章节目录：通用基础与专题扩展

## 目标

每个专题脉络（P/D）的章节目录本身就是完整课程。专题所需的通用知识（B/M）不放在独立的“学习路线”或阶段表中，而是在使用它的位置以 `[REUSE]` 小节编入专题自己的章、节，并与专题扩展小节交错编排。读者按目录顺序读下去，即走完从必要基础到专题机制与验证的整条路。

正文仍只写一份：通用概念的主归属是 B/M 的具体小节；专题只链接它、说明本章如何使用，不复制或改写。

## 两类叶子条目

```markdown
- 2.1.3 条件概率、联合分布与边缘化 <a id="p09-2-1-3"></a> [REUSE](../../../基础知识/模型方法/统计学习与科学评估基础/README.md#m01-1-2-2)
  - 学习目标：<通用知识本身的最低掌握要求，可沿用原节>。
- 2.2.4 扰动效应估计：设计矩阵、协变量与伪 bulk <a id="p09-2-2-4"></a> [WAITING]
  - 学习目标：<专题特有的推理、比较或判读>。
```

- `[WAITING]` 等四种状态是自有写作任务，唯一由 `scripts/sections.py` 认领、完成。
- `[REUSE]` 是课程内容类型，不是进度状态，没有独立正文目录，不能认领、完成、放弃，也不进入任务统计。它计入该脉络的小节规模（须少于 100），因为读者确实要学习它。
- `[REUSE]` 本身就是指向通用原节的链接，须精确到具体自有小节；不得指向整门课、整章、另一个 REUSE 条目或外部站点；同一脉络不重复 REUSE 同一小节。每个 REUSE 条目须有 `学习目标`，说明在本脉络需要掌握到什么程度。

## 编排方法

1. 从科学任务出发，列出对象、测量、表示、方法谱系、核心机制、训练/推理、数据与验证；不从平台已注册模型反推范围。
2. 对每个章节问：理解这里需要哪几个共同概念？若 B/M 已有主归属小节，就在该章节紧挨着专题小节的位置编入复用条目；若 B/M 没有，说明是缺口，先补 B/M 或在专题新增自有小节，不用复用掩盖。
3. 不同分支（遗传/化学、离散/连续、预测/设计）各取各自最小基础；不让读者为了一条分支先读全部 M03、M04。
4. 一个基础小节的范围大于专题需要时，在学习目标中写明需要的概念与不需展开的部分，而不是暗示全文必修。
5. 核对前置链：下游机制需要的数学和概念必须已在目录的更早位置建立（复用或自有）。校验器不能证明这一点，必须人工检查。
6. 章、节标题仍用名词性知识主题；不再另设“阶段”标题，不并列第二份学习顺序。

## 容量与统计

脉络总规模 = 自有任务 + 复用条目，须少于 100。项目统计同时报告“自有任务”和“通用复用”，任务进度只统计前者。复用也不能成为压缩教学或合并独立机制的理由；若某专题加上复用将超过 99，应按科学关系拆分专题。

## 编号、重排与记录

复用条目和自有条目同在章—节—小节编号序列中。插入或移动条目会改变后续编号，须保存旧新映射并修复入链；本规则首次落地的映射见 `docs/目录审查/2026-11-20-章节整合映射.json`（798 个自有小节一一迁移，309 个新增复用）。

## 验证边界

校验器检查 REUSE 链接是否精确、存在且不是链式 REUSE，是否有学习目标，状态与统计，脉络内不得残留独立学习路线或阶段表。它不能证明课程顺序合理、前置闭合或认知负担适中，须人工复审。

复用不是任务授权：处理一个自有小节时，先读它所在章节前面的复用条目和链接的通用小节，但不得因此认领这些通用小节。
