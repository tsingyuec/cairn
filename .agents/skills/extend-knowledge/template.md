# 新知识脉络 README 模板

复制到对应分类下的新目录并替换占位内容。模板中的占位符不是有效知识目录，不应直接通过校验。按真实主题选择章节，不凑相同结构。每条叶子脉络独立少于 100 小节，分类汇总不限；先充分覆盖内容，不把小节总数当成需要压低的预算。

```markdown
# <主题名称>

编号：<B/M/P/D 与两位以上数字> · 类型：<生物学基础/模型基础/模型专题/数据专题> · 目录规模：<实际小节数> 个小节（三级叶子节点，少于 100）。

**知识主线**：<由科学对象与问题走向机制和证据>。

**范围与边界**：<包含哪些对象，与近邻如何分工；有哪些未确认事项>。

**前置知识**：<只列开始本脉络所需的具体叶子小节链接；没有则写明>。其余基础在下方章节使用处以 `[REUSE]` 小节编入，不要求通读任何上游脉络。

**组织与素材策略**：<适合的课型、默认深度和不应重复的素材>。

> 自有任务进度：`[WAITING]` 待处理 · `[PROCESSING]` 已认领 · `[DONE]` 已验收 · `[ABORT]` 终止。

## 目录

<a id="<编号小写>-1"></a>

## 1 <第一章>

<a id="<编号小写>-1-1"></a>

### 1.1 <第一节>

- 1.1.1 <通用概念的名称> <a id="<编号小写>-1-1-1"></a> [REUSE](<相对路径>/README.md#<来源叶子锚点>)
  - 学习目标：<在本脉络需要掌握的深度，不展开什么>。
- 1.1.2 <明确的知识主题：关键机制或术语> <a id="<编号小写>-1-1-2"></a> [WAITING]
  - 学习目标：<必须学会的推理、比较或判读；明确不展开什么>。

## 学习出口

<后续脉络链接；不等于硬性前置依赖>

## 原始资料与延伸阅读

<论文、官方仓库、原始数据发布；内部资料说明授权和证据边界>

## 导航

[返回分类目录](../README.md) · [知识总目录](../../../README.md)
```

专题的章节目录把通用复用与专题扩展交错成完整课程，格式、容量及统计规则见 [整合式章节目录](curriculum.md)；B/M 基础脉络没有专题复用时可只含自有小节。不能只填一条示例后把其他章节留作读者自行探索。

## 标题约定

章、节、小节均直接写知识主题与关键知识点。不要使用“如何／怎样／为什么”或“读懂／学会”等问句、指令式标题。核心问题用于确定粒度，写入学习目标，不直接充当标题。简短明确的名词性标题也可以，不强制所有名称都加冒号。

## 引用方式

相对路径从 README 位置计算。若新条目位于 `content/专题知识/模型/<主题>/README.md`，引用几何学习基础的例子为：

```markdown
- 1.1.1 几何变换下的不变预测与等变预测 <a id="p12-1-1-1"></a> [REUSE](../../../基础知识/模型方法/图神经网络与几何学习/README.md#m03-3-1-2)
```

链接指向“几何变换下的不变预测与等变预测”，不是整门图学习课程。同一分类的兄弟脉络从 `../<兄弟主题>/README.md` 引用。

## 物理目录与状态

只建目录时保持 WAITING，不预建空正文。实际写作时正文路径为：

```text
<系列>/
├── README.md
└── 1.1_<节名>/
    └── 1.1.1_<小节名>/
        ├── <博客标题>.md
        └── assets/<博客标题>/
```

目录不另建章层级，标题里的复用链接注记不参与文件夹名。执行 `scripts/sections.py list` 获取规范落位路径；状态由主会话精确更新，详见 [小节处理规则](processing.md)。

## 复用既有博客时的导读

同一博客只存一份；其他小节在其规范目录下建立 README，不能复制改写原文。例如：

```markdown
# <本小节的阅读导引>

## 学习目标覆盖

- <目标一>：由下方既有博客的某一节/案例解释。
- <目标二>：指出另一段实际证据；不能只说“相关文章”。

## 阅读材料

<从当前导读到项目内真实博客的相对链接，不是另一个 README，不是外站链接>
```

如目标仍有缺口，补合适素材或报告，不能仅凭导读格式和链接存在就完成。详见 [学习单元粒度规则](granularity.md)。

## 不同主题应关注什么

模型：科学任务 → 表示 → 核心架构 → 训练监督 → 推理/采样 → 同任务比较 → 评价证据 → 局限。逐项检查关键机制的具体落点，不把这条完整学习链直接装成一个“模型机制”小节。不同单元可共用同一报告；通用 GNN/Transformer/扩散概念复用基础。

数据：原始提供方 → 实验设计 → 实体和测量 → 发布与血缘 → 关联资源 → 科学任务和偏差 → 许可。不写成本地数据库字段或接口手册。
