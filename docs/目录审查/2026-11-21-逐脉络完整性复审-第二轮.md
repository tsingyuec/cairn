## 六类共性问题

### 1. 前置悬空

概念在目录中先用、后建，或前置只写在标题/目标里，读者按顺序读不到。典型：B02 1.1.5 用剪接和翻译举例，但两者都在其后；B03 4.1.1 的效应量早于 2.1.5 的 Tm/ΔG；B04 4.2.2 用效应量却漏挂 M01 §3.1.1；B05 4.1.2 的折叠/聚集在 4.2.1 才用；B06 2.1.1 的概率分布早于 3.1.2；M01 2.1.5 的正则化早于验证集；M02 3.2.2 用线性探针早于 4.2.1；M03 5.1.3 的模型验证夹在训练节；M04 2.1.4 的 KL 早于期望；P01 3.2.8 用 pLDDT/PAE 早于 5.2.2；P02 1.3 用语言模型分布和联合生成早于 2.1.3/3.1.2；P05 1.3.5 的自由能晚于 1.3.2/1.3.4；P06 1.1.4 的 SAFE 前置指向未编入的 M04 §4.1.3；P07 2.1.4 的反向互补早于 M02 §1.2.4；P09 2.2.4 的“设计矩阵”早于 2.3.1；P11 2.3.2 的 IoU/边界框早于 3.1.2/3.1.4；D02 2.1.6 的 profile HMM 晚于 2.1.5；D04 4.2.2 的邻域聚合与后文无关；D07 1.1.4 的伪重复只写在标题注释里。

### 2. 内联前置未编为 REUSE

用“前置 [X §y]”写在标题或目标里，但没有独立 REUSE 小节，因而不进入课程序列，也不计入统计。典型：B05 3.2.2；P02 5.1.6；P03 4.1.1/4.1.2（只写“引用 P02”无链接）；P04 2.1.3/4.2.1；P06 1.1.4；P10 4.2.3；D02 3.1.3；D03 1.2.5；D07 1.1.4。按 `curriculum.md`，这些应改为正式 `[REUSE]` 条目，或删去前置并写清边界。

### 3. 自有单元与 B/M 重复

同一机制在基础脉络和专题脉络各建一次，且专题侧没有收窄为判读/应用。典型：B04 4.2.1 与 M01 2.1.4 的计数似然；B05 4.2.3 与 5.1.8 的表达纯化；M01 4.1.4 的“校准”与 4.2.1；M03 4.1.3 与 3.2.2 的局部框架；P01 5.2.5 与 B03 5.1.3 的化学合理性；P06 5.2.2 与 B06 4.2.1 的适用域；P08 3.1.5/1.2.2/6.1.3 与 B04 的 NB/ZINB、聚类、批次；P09 1.2.6 与 B04 4.2.4 的细胞组成；D06 4.1.3 与 P06 5.1.4 的骨架去重。

### 4. 评价与验证环节缺位

专题的主线终点是“能判断结果是否可信”，但目录只有生成/预测，没有对应验收。典型：P01 缺 DockQ 与 CASP/CAMEO；P02 缺 TM-score/lDDT/界面指标；P03 缺置信度判读与 ΔΔG；P04 缺结合测量；P05 缺位姿物理合理性；P06 缺性质代理打分器；P07 缺生成质量指标；P08 缺注释可信度；P09 缺剂量响应与未见时间点；P11 缺图表数值反演评价；D01 缺 VCF 归一化；D03 缺许可/访问；D04 缺样本级通路活性与网络显著性。

### 5. 方法谱系偏窄

一条脉络只围绕少数模型，缺少经典/统计/相关路线及适用条件比较。典型：M01 缺聚类、因子设计、混合效应；M02 缺非神经序列基线；M03 缺“不变量特征/数据增广/等变架构”三条对称性路线的取舍；M04 缺生成路线总对照与离散转移核；P02 骨架侧只有 RFdiffusion；P04 缺环肽设计路线；P05 缺形状—药效团筛选；P06 缺图生成；P07 缺 RNA 折叠动力学；D02 缺 UniParc；D06 缺 Murcko 骨架与靶标标识解析。

### 6. 生物学/数据前提缺失

模型或资源之前缺少必要的生物学环节。典型：B02 缺变异来源、错配修复、端粒；B04 缺细胞组成统计与正交验证；B05 缺 Ig 类别/亚类与效价；B06 缺肽合成与前药；D01 缺 SV 概念与受控访问；D03 缺零值语义、伪重复、图谱门户分工；D06 缺本体读取前置。
