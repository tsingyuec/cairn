## 历史结论：按视频与博客覆盖重审目录

原目录能表达知识范围，但还不是适合直接派给 agent 的教学任务目录：一些基础小节塞了多种独立机制，另一些模型和资源小节却只是一个字段、一句警告或已经讲过的基础。**问题不只是“拆得不够细”，而是把知识概念、可讲授的学习单元、素材和处理任务混在了一层。**

本轮保留 28 条脉络，重排为 **531 个待处理学习单元**：基础部分由 227 增至 261，模型专题由 244 调整为 182，数据专题由 167 调整为 88。总数减少不表示基础教学被压缩，而是细化必要机制，同时合并碎片和移除重复采集任务。

本轮没有生成博客、没有认领真实写作任务，也没有修改 video2blog-content。全部新目录仍为 WAITING。

## 从实际博客观察到的特点

### 一篇短视频也可能适合联合讲一组指标

[AlphaFold Server 教程](https://www.youtube.com/watch?v=cEJca3gMhbw)对应博客约 6 分钟，连起提交结果、pLDDT、PAE、pTM 和 ipTM，核心是“读懂一个预测结果”。这支持把四类指标作为一个联合判读单元，而不是因有四个缩写就建立四个独立采集任务。

参考目录把它归在 pTM/ipTM 下，但正文明显超出该窄题目。**有一篇文章挂在某小节下，不等于文章的教学范围与小节一一对应。** 本轮 B03 保留联合读分数；置信度头的训练机制则留在模型专题。

### 一篇长报告常同时支撑多个学习问题

[DiffDock 作者讲解](https://www.bilibili.com/video/BV1a3411X7K5/)对应博客约 57 分钟，覆盖多峰预测、平移/旋转/扭转、扩散、置信度训练、排序、评价和限制。若每个名词都派成独立任务，很容易让多个 agent 完整复述同一场报告。

本轮将“位姿生成机制”和“置信度与结果判读”组织成互补单元，并允许它们引用一篇规范博客的不同部分。不是禁止同视频被再次引用，也不是强迫另找一支质量较差的视频。

### 处理链中的步骤未必应拆成多个任务

[单细胞归一化讲解](https://www.youtube.com/watch?v=huxkc2GH4lk)对应博客把缩放、log、平方根、Pearson 残差放在同一个分析目的中。适合一个有明确边界的归一化单元；高变基因是另一项特征选择决策，另设单元。

[多头注意力实现讲解](https://www.youtube.com/watch?v=Iy7jiVsJ0fw)围绕投影、分头、view/transpose、合并讲一条计算链。Q、K、V 或每次张量重排不应各变成一节；对本项目的基础层，也不要求完整复刻 AI 基建课程的实现深度。

### 真正不同的阶段可以自然拆开

[RFdiffusion3 骨架教程](https://www.bilibili.com/video/BV1ohbH6aETT/)和[MPNN 续篇](https://www.bilibili.com/video/BV1uDbW6tE3c/)对应两支不同的视频，前者产出骨架，后者消费骨架并生成候选序列。按输入输出和阶段拆分有真实素材支撑，不只是把一个视频按关键词硬切。

### 资源介绍常是一个完整的实验故事

[Tahoe-100M 研讨会](https://www.bilibili.com/video/BV1qpb9zMEjd/)对应博客约 40 分钟，覆盖混合细胞系、给药、身份解卷积、资源维度、应用案例和局限。字段和版本信息可以在同一个实验设计/条目判读中理解，不需要每个标签单独去找视频。

本轮 D03 保留“实验设计”和“发布产品判读”的不同目标，但不再分别为每个孔位、标签或计数层派任务。

### 名字出现了，不等于专有机制已被覆盖

[GenMol 概览播客](https://www.youtube.com/watch?v=QnCABenp3YE)对应博客约 11 分钟，提到 SAFE、离散扩散、分子编辑和应用愿景。它适合概览，但不自动满足“解释算法如何运行”的目标。

[MOE 抗体可开发性讲座](https://www.bilibili.com/video/BV1Gc41157U4/)对应博客约 61 分钟，主线是 MOE 的建模、描述符和风险改造。它能解释可开发性背景，却不是 ABDP 内部训练、特征或标签定义的直接证据。原参考目录中的 ABDP、BioPhi 等选题说明也记录过专名素材不足、改用通用视频的情况。这是需要显式暴露的覆盖缺口，不应靠标题把它抹平。

另抽读了 [GNN 入门精读](https://www.bilibili.com/video/BV1iT4y1d7zP/)和[自回归到 LoRA 综述](https://www.bilibili.com/video/BV1an846BEPE/)。它们都跨多个相关概念，说明综合讲解可以作为共同材料，但不能据此断定每个机制均有足够深度。

## 这轮采用的划界标准

1. **一个核心问题**：读完能解释一种机制、完成一种判读、比较一组有内在联系的对象，或走通一条来源链。
2. **目标深度明确**：导览只建立地图，机制课要读通信息流，资源课要能核对原始对象。不能把比较课无限扩成各方法的完整教材。
3. **素材默认预算而非完成标准**：通常 1–3 篇互补博客；三篇仍有目标缺口就不能 DONE。需要更多材料时先判断独立主线是否该拆分，不机械增加或硬守篇数。
4. **共讲有理由，拆分也有理由**：QKV、联合置信度、归一化步骤可共讲；求梯度与更新参数、不同统计推断、独立模型机制宜分开。
5. **纯复用不重复排队**：基础阅读入口不再创建 WAITING；结论性警告并入对应案例的验收。
6. **资源按使用故事组织**：读一个基因注释、一个变异断言、一次药物筛选或一条证据链，而不是一个字段一篇博客。
7. **专有事实必须直接核对**：通用教程不能替代特定模型、发布产品或内部实验的直接资料。素材不足先报告，不偷偷降低目标。
