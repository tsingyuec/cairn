# 逐脉络完整性复审

日期：2026-11-21。

> 本文记录第一轮复审及三步补缺完成时的状态（1292 个条目）。之后第二轮复审又修复到 1406 个条目，见[第二轮复审修复说明](2026-11-21-第二轮复审修复说明.md)；本文数字保留为历史快照。

## 方法与范围

28 条脉络各由一个只读子智能体独立审查，互不共享上下文。每个审查者读完整 README、`granularity.md`、`curriculum.md`、REUSE 指向的 B/M 小节和同分类 README，回答五个问题：主线是否完整、方法谱系是否只剩少数模型、机制深度是否只有输入输出、REUSE 位置是否合理、有无冗余错位。原始报告见[明细](2026-11-21-逐脉络完整性复审-明细.md)。

这是目录层审查，不是正文审查。审查者没有联网核对论文，判断依据是目录声明、已有单元和项目内检索；标“证据缺口”的条目需要一手资料确认。

## 总体结论

28 条脉络全部存在主线缺口，没有一条被判定为“完整”。共提出约 160 项，其中约 20 项是补 REUSE（基础已在 B/M 但未编入），其余为新增自有小节。缺口不是零散的“可以更深入”，而是集中在几个可复现的模式：

1. **经典与统计路线缺位**：M02 没有 n-gram/马尔可夫/PWM，P06 没有 SELFIES 与遗传算法/库枚举，P05 没有进化保守性与模板法口袋预测，P04 没有描述符 QSAR，P03 没有模板同源建模，P02 没有传统打分函数设计。方法谱系实际只剩“被审查的那几个神经模型”。
2. **评价与验证环节缺失**：P01 缺 TM-score/lDDT/DockQ，P05 缺富集因子与诱饵集，P08 缺注释与整合指标，P11 缺 IoU/mAP，P02 缺 in silico 成功率，D05 缺相似度排序评价。目录写了“评价”章节，但没有可判读的指标单元。
3. **数据与实验前提缺失**：B04 缺读段质控与 ChIP/CUT&Tag，P09 缺归一化对效应量的影响，P02 缺训练结构语料分布，D03 缺定量路线与细胞过滤，D01 缺 dbSNP/HGVS，D06 缺跨资源化学标识映射。
4. **机制链断在“表示/训练”**：M03 缺边特征与训练监督，M04 缺 KL/先验后验的 REUSE 与能量模型训练，P02 的 RFD4-Proteina 只有输入输出，P11 缺检测框监督与解码。
5. **REUSE 位置与归属错位**：多处基础排在其首次使用之后（M03 注意力、M04 梯度、P10 导数、M02 网络梯度）；P02 §4.1.1 甚至 REUSE 了 P01 的自有任务（`p01-3-1-2`，仍 WAITING），不是 B/M 主归属。

## 横向观察

- **B/M 的缺口会向下游放大**。B01 缺遗传密码、M01 缺交叉验证时，P01/P03/P08/P09 的 REUSE 落点实际上是空的。补录顺序应先 B/M，再 P/D。
- **“评价”普遍被写成一句目标而不是单元**。多个脉络的“评价”节只有“说明指标含义”，没有指标定义、基准集和判读规则。
- **专有模型仍是方法谱系的中心**。P02/P03/P06 的章节按模型名组织，审查者反复指出“无法判断该模型相对经典路线的增量”。
- **REUSE 与自有小节的边界不稳**。D07 把 B05 已有的“抗体形式”“亲和力”写成自有；B06 该 REUSE B03 的酶抑制模型却未接；P02 反向 REUSE 了 P01 的自有任务。

## 同时发现的结构性问题

1. **168 个自有小节没有学习目标**（798 的 21%），分布在全部 28 条脉络，M02/B01/B05/M03 各 10–11 个。校验器只要求 REUSE 有目标，自有任务不强制；这些小节无法验收深度，且被下游 REUSE 继承后缺口扩散。
2. **35 处标题内仍写“复用 [X §y]”**，是旧格式残留。它们既不是 REUSE 行，也没有状态语义，与新的 REUSE 行格式冲突。
3. **P02 §4.1.1 的 REUSE 指向 P01 §3.1.2**，跨专题引用一个尚未写作的自有小节；正文尚不存在，4.1.2 实际没有前置。
4. **REUSE 前置倒挂**：至少 M03（注意力）、M04（梯度/期望）、M02（网络梯度）、P10（导数）四处，基础排在其首次使用之后。
