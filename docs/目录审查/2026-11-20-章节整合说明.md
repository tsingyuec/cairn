# 章节整合说明：通用基础并入专题目录

日期：2026-11-20。

## 变化

上一版在每条脉络的目录前加了“学习路线”，列出阶段、基础精读、阅读边界和通过标准。它把课程拆成路线和目录两份，读者要在两处来回跳转。本次取消：**各脉络的章节目录本身就是完整课程**。专题所需的通用基础（B/M）以 `[REUSE]` 小节在使用处编入专题自己的章、节，与专题扩展小节交错编排。

例如 P09 第 2 章“矩阵、概率与扰动响应统计”，在同一章中先后包含条件概率、效应量与检验（通用，链接 M01），以及扰动效应估计、非配对细胞数据（专题自有）。GEARS 与 chemCPA 分支仍各取各自最小基础，位于各自章节之中。

## 条目类型

- **自有写作任务**：`[WAITING]` 等四种状态，沿用原编号与锚点的映射，一一迁移，状态不变。
- **通用复用**：`[REUSE]` 加括号内来源小节链接，条目本身就是指向具体 B/M 自有小节的链接，另附 `学习目标`。无进度状态、无独立正文、不可认领；计入脉络规模，不计入任务统计。

## 迁移与验证

- 映射：`2026-11-20-章节整合映射.json`（798 个自有小节新旧编号、309 个复用条目及其来源），是 735 → 798 之后的第四层映射。旧锚点不重定向；项目内 129 处链接已按映射改写。旧的 `*-route*` 锚点已删除，指向它们的链接改指新目录第一章。
- 此前的路线阶段基础清单即复用条目的来源，每个阶段引用的基础小节均已编入对应脉络，不存在丢失（迁移脚本断言）。
- 校验器取消路线检查，新增复用来源、应用说明、不链式复用、不带状态等检查；`sections.py` 拒绝对复用条目的认领、完成、放弃。

## 仍需人工判断

- 复用条目位置的合理性、顺序是否数学闭合，校验器无法证明。
- REUSE 条目的学习目标目前由目录规划写成，进入正文编写前须按实际素材复核。
- 复用来源的学习目标来自原节；使用深度的缩小范围需在该章应用中进一步细化。
